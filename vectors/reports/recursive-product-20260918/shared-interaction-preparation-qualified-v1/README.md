# Shared typed interaction preparation qualification

The shared frontend owner `src/frontends/riscv/recursion/air/prepared_interaction_generation.zig` now owns cold typed interaction generation, exact per-domain decomposition from the existing inverse plane, optional independent reference comparison, and tuple projection. The detached leaf core and Ethereum transcript preparation delegate to it. The replaced generation/decomposition bodies were removed from the CPU integration.

Destination placement, retained staging, receipt validation, and publication remain with the existing callers. A diagnostic or ledger failure can follow staging writes, so the shared result explicitly provides no publication capability and returns no audit on failure. Caller publication remains conditional on complete success. Protocol equations, transcript inputs, column layout, and challenge binding are unchanged.

Qualification: 32 focused ReleaseSafe tests and 14 dependency ownership checks. Focused coverage includes audited and unaudited columns/claims against the existing framework writer, independent cold domain sums, diagnostic tuple records, exhaustive allocation-failure cleanup, and the existing Ethereum ownership checks. The Ethereum audit still requires exactly two allocations including output storage. An initial test fixture incorrectly passed the binding rather than its runtime to the framework; the retained compile log records that correction.

Complete CPU and Metal runs each rebuilt their artifacts from the same frozen source snapshot, generated the four-segment tree, and verified serialized artifacts in fresh processes after producer exit. Each backend passed 192 acceptance/rejection checks, including same-geometry statement substitution. All 21 serialized key/claim/proof artifacts match each other and the canonical baseline. Metal qualification continues to require the native-table and parent typed-interaction dispatch markers.

This is an ownership checkpoint, not completion of all leaf preparation migration or leaf typed GPU interactions. The concrete leaf bundle still binds a native capture to the CPU engine, the core preflight/authority remains in `recursive_fri_outer`, and the noncore owner still imports the concrete leaf type. Migrate those owning contracts before extending GPU dispatch across all 37 typed leaf components. Parent typed GPU dispatch is already qualified separately. No speedup or production-security claim is made here.

`source.patch.gz` and `source-snapshot.json` capture the qualified code before this report and the later goal-document update. `cpu-summary.json`, `metal-summary.json`, and `cross-backend.json` record pinned artifacts and the local full evidence directories. `focused.log` and `ownership.log` retain the bounded checks.
