# RISC-V proving-stack measurements

Retained inputs, logs and receipts for the bounded proving-stack reset.
Original measured evidence is immutable; paths inside historical receipts refer
to the checkout and tooling used for that measurement. `historical-run.py.txt`
is the original diagnostic invocation, retained as evidence, not maintained tooling.

Current commands and acceptance boundaries are in
[`design/riscv-proving-stack/plan.md`](../../../design/riscv-proving-stack/plan.md).
The maintained timing parser is [`scripts/riscv_composition_report.py`](../../../scripts/riscv_composition_report.py).
