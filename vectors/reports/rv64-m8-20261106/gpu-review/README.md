# m8-gpu review-1: GPU-native driver / capture / recursion findings

Branch `codex/rv64-m8-gpu`. Fixes: 91c5fb735 (outer knobs and checks) and
1b73dc0d3 (driver, contract v2, capture, worker, recursion registry), plus the
receipt commit. Every finding was checked against the code at 98b541033.

## Dispositions

| # | file | finding | verdict | fix |
|---|------|---------|---------|-----|
| 1, 18 | m8_capture_stream | `sealed` rows never compared with the plan; `chunk` accepted late or non-contiguous chunks | CONFIRMED | `prepare(segment_rows)` stores the planned rows. `sealed` requires rows == planned == chunk row total. `chunk` refuses after the seal and requires `first_row` == the cursor. Each violation fails the stream. 3 negative tests. |
| 2, 8 | worker / driver | a failed or refused Stage1 never released its ring buffers or failed the capture, so the request hung | CONFIRMED | `BatchJob.after` is enqueued when every gate succeeded, whether or not the body did. `BatchJob.on_fail` calls `Stream.fail` on refusal, a failed dependency, an enqueue error or `failBatch`. `detach` (every begin and finish path) cancels the capture when a gate is still unsealed, waits for `done`, and then returns the buffers. driver_test: ring 2 < 3 segments with `refuse_stage1 = 0` fails closed, the ring is whole afterwards, and the next request proves. |
| 3, 17 | gpu_native / driver | one partial flag per device, which a GPU without segments never publishes | CONFIRMED | `Exchange.partial_mask`: only GPUs that host segments own a partial slot (dense flag rank). The driver sets the mask from placement. driver_test: a 1-segment request on 2 GPUs proves. |
| 4 | outer_device | `classOf` keyed by `(kind, ordinal)` | CONFIRMED | The registry is keyed by an authority digest (kind + the class keys of the children; a truth's ordinal names its statement kind). `RecursionFactory.class_of(id, children)`. The driver passes the segment, truth and node class keys in topology order. Test: two block shapes with swapped ordinals resolve to the right classes. |
| 5 | outer_device | the ClassEntry borrowed a statics pointer that LRU eviction can free | CONFIRMED | `ClassInfo.pin` is a counted reference, `outer_job_prestage.ClassPin` (`StaticsCache.borrow`). The registry holds one reference and each ClassEntry holds its own, released in `destroy`. The pin-balance test covers it. The real eviction path cannot run on the host (`Statics.init` needs the library). lruVictim already skips entries with `refs > 0`. |
| 6 | gpu_native | publish checked only header words the host had written; `len == 0` was accepted | CONFIRMED | Header word 12 is a completion tag that each batch tail writes on the device before its D2H, and publish requires it. The preamble sets the mirror's status words to unset. A zero length is refused for every kind except `.request` (`GpuNativeEncodedEmpty`). |
| 7 | m8_capture_stream | `begin` reset failure and gates and released buffers while the capture thread could be running | CONFIRMED | Request epoch: `prepare` runs before the capture thread starts and is refused until the previous request detached. `bind` never resets anything. `releaseOwner` moved to `detach`, after `done`. A capture that never reports `done` poisons the stream. Test: an early failure plus a held buffer survive bind. |
| 9 | driver_request | a faulted final wait aborted jobs while other GPUs were still running | CONFIRMED | `quiesce()` runs on every lane before finishBatch(false); the driver is then poisoned. |
| 10 | worker | a skipped body or a stage refusal left issued uploads outside the done event | CONFIRMED | `enqueue` waits on `staged_event` whenever the slot had uploads and never waited. The refusal path records `staged_event` on h2d and makes exec wait on it. |
| 11 | driver_request | memory plan mis-sized | CONFIRMED | main_resident = ceil(max_segments / devices) × the largest aligned native MAIN, which bounds what placement puts on one GPU. Phase A/B peaks = max(config, the warmed classes' `arena_peak_words`): A covers classes without `phase_b`, B covers all. Class cache words add `ClassEntry.held_words`, which the factories report. Capacity is (d) below. Test: 4 × 256 words per GPU at max_segments 8 on 2 GPUs. |
| 12 | driver_request / worker | teardown unsafe; plan arena never uninstalled; a half-made Setup leaked | CONFIRMED | `deinit` quiesces and aborts any request in flight. Release waits on its exec stream, then calls `Worker.uninstallPlanArena`, which frees the block and parks the worker. Install releases every lane whose Setup started. Test: teardown with a request in flight aborts all 13 jobs, with no leak. |
| 13 | worker | concurrent `call`s shared one completion | CONFIRMED | Each call has a caller-owned `CallDone`. `requestControl` never overwrites a posted call. Test: 8 concurrent callers, each gets its own result. |
| 14 | driver_request | exchange at a variable offset, so a flag could overlay a stale non-flag word | CONFIRMED | Contract v2: the exchange sits at a fixed offset (64), with flags first and every offset taken from install capacities. A flag word only ever holds a tag or 0. The header and directory are uploaded as two copies around it. |
| 15 | driver_request | the parity came from the generation, so a failed begin cost a parity | CONFIRMED | The parity is a free slot (`next_parity`, alternating). Test. |
| 16 | worker | job i+1 was staged before its capture gate latched | CONFIRMED | `BatchJob.gates` are latched before stage, and the staged job is enqueued first so Stage1(s) never waits for segment s+1. Contract note: `stage()` must not read a dependency's (child's) data. |
| 19 | driver_request | plan needs every row count before begin, so capture cannot overlap | CONFIRMED, DEFERRED | This needs late binding of the segment count and class, with the DAG, topology, slab and exchange sized from capacities. Contract v2 already sizes the exchange from capacities. A geometry mismatch now fails closed (#1). Needs the native factory (`native_device`), which has not landed. |
| 20 | m8_capture_stream | a segment larger than the ring deadlocks | CONFIRMED | `Ring.acquire` detects the self-deadlock (every buffer belongs to this stream's unsealed segments) and fails the stream. Plan refuses a class whose `ClassEntry.capture_words` exceeds the ring. Test. |
| 21 | outer_device | `register` is never called outside tests | CONFIRMED, DEFERRED | The warm entry has to prestage and call initWhole per class of the install-time class mix. That needs the class manifest and `truth`/`node`, which have not landed. Documented in outer_device. |
| 22 | outer_device | `c_allocator` default; the linkLibC workaround | CONFIRMED | `a` is required; driver_serve passes it and calls `deinit`. linkLibC was dropped from test-rv64-jobs, and outer_device tests were added to that root. |
| 23 | outer_checks | private CHK1 field with a 32-bit tag | CONFIRMED (hybrid part) | The body memsets the check words to unset before any work, and the graph key moved to device-checks/v2. Wiring the request-slab status word waits for `node()` under GPU-native (#21). The hybrid also cross-checks the host reference, so it was never unsound. |
| 24 | outer_job | env parsed per node; the fault ordinal is live in production | CONFIRMED | `outer_env` parses each knob once per process (std.once) and freezes it. Fault injection is two-key: `STWO_RV64_M8_FAULT_INJECTION=1` must also be set, otherwise service start fails. Also applied to OUTER_FAULT_ORDINAL. A build-option gate was not used because the pod negative tests run the production binary. |
| 25 | driver | GPU_NATIVE is a second flag; JOBS=1 still routes to the legacy feeder | CONFIRMED, DEFERRED | It cannot be switched yet: the factories fail closed, so JOBS=1 would refuse to serve. Folding the hybrid knobs into a default-on JOBS=1 config needs a measured A/B for each knob (protocol: only the final measurement step promotes defaults), and the GPUs are blocked (below). |
| 26 | native_hybrid | framing pool never sealed and off by default | CONFIRMED, DEFERRED | Same reason as #25, plus it needs an install-time class mix, which only the native warm entry provides. |
| 27 | driver_serve | 28 GiB hard-coded | CONFIRMED | `Ops.Exec.memory_info` is optional and resolves to the base image's `stwo_exec_context_memory_info` (cudaMemGetInfo). Capacity = min(cap, free + class cache + the worker's pre-plan arena). Plan failures log every region. Test: shrunk free memory refuses at install. |
| 28 | driver_request | a thread was spawned per request | CONFIRMED | `Worker.post` / `awaitCall`: non-final GPUs' batches are posted to their own worker threads. |
