# Receiver-owned native Poseidon adapter

Status: proposed integration [E]. The actual D2 gate in `../d2-native/` selects raw-Blake only. Poseidon Core fixtures do not activate RV64.

The current `gkr_local/worker_protocol.zig` fixes OM31, prefixed-Blake Merkle, raw-mod-Blake channel, physical proof type and wire family in one authority. Equal numeric PCS configs cannot distinguish raw-Blake D2 from Poseidon D2. Do not append a colliding config to `Candidate.PROFILES` and let `profileFor(config)` guess its suite. Preserve that frozen legacy helper; a new receiver-owned descriptor must choose `{suite version, native format, PCS profile, source AIR/GKR roster}` before decoding a physical proof. Its identity must include the named Core suite identity, native source class, full PCS structure and sampler/retry policy.

A practical seam is `worker_protocol.ForSuite(comptime Suite)` exposing Secure/Hasher/Channel/MerkleChannel/Prover/Proof/Wire plus shared framing visitors. Existing public aliases remain the exact raw-Blake instantiation. A separately named Poseidon worker module uses the new descriptor and9-word roots; classic physical worker, fixed binding/cache, capture and native CPU/truth verifier modules need the same suite type. No32-byte root ABI may truncate or reinterpret a36-byte Poseidon root. Fixed authority, worker wire magic, manifest/chain domains, root admission and Tnat class hash must change together. Source geometry and schedule admission stay receiver-owned.

A first explicitly mixed profile may use Poseidon PCS/FS while retaining reviewed raw-Blake native-GKR/canonical-chain transcripts, but its name and identity must pin that mixture. A complete Poseidon migration additionally needs generic native-GKR strict draw/begin/receipt adapters, section profile identity, corresponding in-circuit transcript, and canonical summary/chain visitor migration. Byte-digest public words are not interchangeable with canonical M31 digest limbs. Public/root hashing for an on-chain Blake/Keccak wrapper remains a separately identified layer.

Qualification order: instantiate the suite seam in a real small CPU and each truth-family proof; fresh receiver and wrong-suite/version/field/noncanonical/root/opening mutants; exact native/circuit transcript replay; actual recursive cell census at source classes; global memory planner refusal/success cases; then both dev blocks with source-frozen binaries and cache-disabled independent receivers. V2 u32 counters require explicit source draw caps and exhaustion tests. CUDA work requires a new36-byte root/9-word Merkle and transcript ABI, per-session custody, device P20 grinding parity and global memory accounting. Keep all selectors unavailable until the corresponding producer/receiver/circuit path is complete. No wall-time claim follows from primitive CUDA vectors or query-count proxies.
