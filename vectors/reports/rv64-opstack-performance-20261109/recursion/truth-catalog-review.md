# Native pure-P2 truth recursion qualification

The complete recursive statement now covers all thirteen native catalog cases, plus classic secp DOUBLE as a fourteenth control. It reuses `truth_role.emitShape` for classic Keccak and secp product/linear/range components and `truth_v3_role.emitMainWithSpan` / `emitGlobalWithParameters` for SHA, modular arithmetic, canonical curve and delegated secp operations. No arithmetic equations are duplicated.

`pure_p2_truth_worker.verifyWithCapture` performs the existing fresh native verification and optionally retains its verified PCS capture. The default `verify` retains the previous behavior. The new statement follows the native pure-P2 worker transcript exactly, including its profile identity, kind, immutable setup identity, local draw domain, manifest-derived global challenges and physical claim framing. Mask offsets use the global lifted domain, while constraint denominators and last-row anchors use each independently sized source component.

The exposed public frame contains the worker ordinal, expected statement, full nine-coordinate fixed/MAIN/manifest roots, every OM31 claim and the call count/first ID. Its expected nine-coordinate digest is recomputed independently from these words. Classic local claims close inside the circuit. Execution-wide coverage, public-word equality and KIO/Wire claim closure remain responsibilities of the independently admitted aggregate receiver; a standalone truth fragment does not accept an OP execution.

All fourteen actual native fragments pass fresh native verification, complete numerical PCS/FRI/OODS circuit evaluation and eight circuit mutations: MAIN sample, claim, ordinal, statement word, ninth manifest coordinate, call count, first ID and ninth output coordinate. Every circuit uses zero Blake gates. Seven filtered ReleaseSafe tests pass. The receipt records native proof sizes, P2 permutations and recursive trace cells per case.

Representative SHA and Keccak leaves additionally produce physical recursive proofs of 700,516 and 701,272 bytes. Fresh trace-only authority reconstruction accepts each proof. A changed ninth expected output and a changed proof byte are rejected. These are correctness gates, not controlled performance results: SHA used a one-worker fixture; Keccak used eight workers. Existing immutable setup and physical-prover costs remain optimization work.

Run all numerical catalog gates with `zig build test-riscv64-op-truth-recursion -Doptimize=ReleaseSafe -j1`. Set `STWO_OP_P2_TRUTH_PHYSICAL=sha256` or `keccak` for the selected physical representative; `1` runs physical leaves for every case. The target deliberately keeps production OP admission closed. Security remains a 128-bit target under documented assumptions, with `security_qualified=false`.
