The main retained-memory reduction beyond dense source rows is the scratch arrays previously kept in three source arenas. For D+F total DEEP/FRI graph nodes, those were approximately 4(D+F) bytes for answer use counts, 4(D+F) for query use counts, and 5(D+F) for opening masks/use counts: 13(D+F) bytes, excluding allocator rounding. They still cost construction memory, but no longer remain alongside the complete parent. Scalar source storage changes from 56N live+dense-fixed bytes to 24N+4P bytes, where P=max(2,nextPowerOfTwo(N)); query byte sources change from 264N to 36N+96P. These are work/storage formulas, not measured speedups or a peak-memory guarantee. Final assembled columns overlap upstream owners until the existing release phase.
