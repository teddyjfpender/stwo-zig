## Production contracts

* `ram_range_forest_plan_v1.derive` calls the original strict lane/range planner,
  preserves lane ordinals and exact shard request counts, and constructs the
  minimum number of fan-in-four parents. A shard with L lane leaves uses
  ceil(L/3) parents including its ONE original range child. The S closed shard
  roots require ceil((S-1)/3) further parents. Empty RAM uses no memory proof.
* `ram_range_forest_authority_v1.Owned.init` independently admits original
  lane/range policies and copies their schedules. It owns geometry, proposed
  summaries and an authenticated local recipe tree. Original Prepared policies
  and original lane/SourceSeal metadata are borrowed and must outlive it.
  Every selected node checks recipe membership; reception does not recreate
  inactive descendant Native.Prepared admissions.
* A summary has full u64 event/request header fields and 22 secure claims:
  transition, predecessor, initial, endpoint, endpoint count and every original
  17 range plane. Partial nodes conserve all17 planes. Each shard adds its one
  fresh range sum and requires exact local zero. Higher aggregates require each
  child already closed independently, so opposite shard deficits cannot pool.
  Request totals may exceed M31 only at aggregate nodes; no modulo field count
  substitutes for their full independently pinned u64 header census.
* Full producer Bus.Owner + Preparation retain at most four actual captures;
  original Child.prepare supplies actual transcript/composition/FRI/DEEP/path
  verifier equations. Routed original byte cells bind sums, counts, local
  headers and compact outputs. Original Boundary suppliers are appended inside
  the parent. Its external recursion-wire schedule is exactly empty.
* SummaryReceiver verifies the genuine original Parent proof against the same
  VERSION19/key/channel/fixed grammar while retaining only independent policy
  and compact summary. Source borrows that actual Fresh, normalizes its original
  transcript and exposes no external public terms. No host summary grants Fresh.
* `Stage.ForBackend(B).publish` loads at most four owned proof proposals on one
  shared bounded budget, freshly verifies the original RAM/range/lower-node
  providers, prepares/proves/encodes through the original worker, frees the
  producer/capture owners, freshly CPU verifies the resulting node, then invokes
  the synchronous copying sink. Prior publications are provisional on failure.
  Loader must bound allocation before returning bytes. Independent specs must
  already pin actual geometry/key IDs; this stage never selects keys from bytes.
* Final public policy uses PAGE Summary.Source and memory Summary.Source. It
  checks exact original B5SS/source pins, Source9/Word epoch, root census and
  full memory coverage. Original PAGE/Fold closure is repeated; predecessor,
  initial sign, endpoint sign/count and17 closed range planes are constrained.
  Its sole secure output is the still-OPEN transition sum. True empty RAM still
  requires a genuine PAGE root and zero source endpoint/initial obligations.
