# Caller-only native physical frame v1

`block_v5_native_frame_v1.zig`, its PCS component and native-v3 integration now produce and freshly verify the actual caller-only native STARK and genuine recursive leaf/outer proofs. The pure semantic gate passed 3/3. The complete SHA/Keccak caller bundle also passed fresh global accounting and exact recursive reception in the combined 13/13 gate. This qualifies the diagnostic q8/PoW0 caller fixture, not an Ethereum block or canonical caller performance; see `block-v5-complete-caller-q8.json`.

A native-v3 shape with no ordinary components and no clock infrastructure still needs a real native STARK for the recursive verifier. Both PCS engines correctly reject a zero-component composition (`InvalidCompositionLogSplit`); that generic guard remains unchanged. The logical shape and its zero native lookup census remain unchanged as well.

The opt-in physical frame uses fixed selector1, four constant main columns `[B5NF, version1, total_steps, external_retirements]`, and one constant-zero interaction pad, all at log2. Six real quotient equations enforce selector1, four selected main/geometry equalities, and zero pad. The pad produces no LogUp claim or event; it preserves the strict artifact preflight requirement that fixed/main/interaction/composition trees have actual columns. No zero receipt or zero STARK bypass is introduced.

All frame values are invariant admitted geometry. PCs and register/public endpoint values remain authenticated by the public admission and native instance identity, supplied to the reusable recursive public bus, and closed by real caller state/global memory proofs. Putting endpoints into recorded setup constants would silently specialize the recursive key; this design avoids that change. Different valid public PCs with equal geometry have identical frame columns but different public admissions.

Native-v3 integration selects frame physical column logs and independently reconstructs the fixed selector, includes the versioned frame geometry in template identity, appends its actual AIR handle to native component ownership, commits the pad in Tree2 and records these same six constraints in native-v3 recursive composition. Ordinary v3 and every old v2/full route retain their existing columns and AIRs. Logical empty program, memory and six-table partitions still match a fresh native receipt and retain public PC/clock compensation for caller retirement closure.

APIs: `required(shape)`, `expected(shape, external_retirements)!Expected`, `fixedColumns`, `mainColumns`, `interactionColumns`, `freeColumns`, `mixGeometry`; `evaluateGeneric(S, selector, row[4], pad, expected[4])[6]` and `symbols(S, Expected)` share semantics with recursive recording. `Component{expected}` implements both PCS quotient paths. The pure test rejects mutated selector/tag/step/pad, wrong external count and nonempty clock infrastructure, and compares equal frame geometry across distinct independently valid public admissions. It grants no proof authority.
