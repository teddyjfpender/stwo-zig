## Exact semantics and bounded stream

`block_v5_memory_source_batch_fold_v1.Merge` merges the two sorted nonzero initial
image files with the paired sorted first-touch/final files. Each physical union
leaf carries source stream/ordinal, value-before, value-after, complete u64
clock and touch ordinal. A touched omitted initial word has before=0. An
untouched image word has after=before. Public-input authentication fixes initial
values; it does **not** prevent legitimate final RAM writes to input addresses.
Program/out-of-range/unaligned/register-space records fail closed.

`Cursor` traverses the exact original depth-30 tree with 31 stack frames, one
union leaf and three source-record peeks. It emits one postorder operation at a
time: canonical empty subtree, live union leaf, two-child branch, or the unique
root consumption. Both roots travel through the same coordinate topology.
Each coordinate is emitted once. Defaults are independently reconstructed once
at compile time, rather than rehashed for every operation. No node map, full
image, endpoint list, openings or per-edit sibling paths are retained.

Host root matches are candidate consistency checks only. Equation authority
requires actual fresh proofs and all joins below.

## Exact joins and omission resistance

The new coordinate bus(67) supplies each operation's `(height,index,before,after)`
and consumes both exact child coordinates at branches. Only the admitted

initial/final root pins. Levels strictly decrease from parent to child, and all

The framed hash bus(97) is `(leaf/node tag, payload64, digest32)`. Each live leaf
and branch requests both initial and final hashes. Equal requests can share one
actual provider with independently fixed multiplicity two. Zero/default frames

same hash bus. Neither defaults nor equality permit dropping a request.

## Actual packed hash core path

`block_v5_memory_source_packed_hash_v1` emits the original 56 G and 16 XOR logical
rows per BLAKE3 compression, with original exact fixed schedules/use counts.
The G layout is main82/fixed16/interaction80 and 32 direct equations; XOR is
main12/fixed6/interaction16. This is byte/word packed BLAKE3 arithmetic, not a
claim that the new bit-routing algebra already uses SIMD.

The connector constrains all external bits, original 32-byte domain/version/
kind header, value/payload serialization, zero padding, block length, counter0,
CHUNK_START/END/ROOT flags and chaining. All 32 initial words are emitted with
exact core plan use counts; all 16 output words are consumed once, including
eight discarded words. A leaf frame is48 bytes/one compression; a node is108
bytes/two compressions. At most one compression's actual G/XOR rows is live.
Sinks borrow callback rows and must copy into independently bounded columns if
they retain them.

Both operation and packed-connector graphs have stable heap budget owners;
transient symbols/builders/evaluation scratch are released, and complete
circuits are published only after successful construction. Fault fixtures cover
all graph-owner allocations. Packed mode returns hash/wire *candidate* sums:
only actual core proofs and fresh bus closure can authenticate them.

## Work counts, not measured speedups

Let N=I+J be full-image nonzero records, U=touched addresses, and L the address
union size. L=N+U-overlap. For each height h=1..30, count distinct union prefixes
`floor(word_index/2^h)`; their sum is B, the exact unique branch count. Empty
terminals E satisfy L+E=B+1. Including the one root consumption, operation count
is `2B+2`. Dense intervals approach linear unique-node work; worst sparse work
still has B<=30L. There is no unconditional linear or wall-time guarantee.

Initial nonzero leaves cost one compression each. Nondefault unique nodes cost
two. A changed final subtree adds its distinct leaf/node computations; equal
initial/final subtrees share computations, while canonical defaults add none.
The old per-edit oracle costs122E_old compressions including insertions. The
bounded257-RW-word fixture predicts fewer than1336 new compressions versus32086
old compressions (and asserts only work counts). Those assertions have not been
run or measured yet. G/XOR table requests, connectors, routing, source SHA and
proof setup remain real costs.
