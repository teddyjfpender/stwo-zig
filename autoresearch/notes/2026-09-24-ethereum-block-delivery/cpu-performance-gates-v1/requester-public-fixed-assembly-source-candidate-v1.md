reconstructed original PUBLIC21 Owner, retry capacity, security profile and

commitment or proof bytes. It validates the exact original requester-only owner,

joined physical layout; otherwise `blake3_g_partition.geometry` determines
exact replacement slices. No MAIN column or dummy witness is allocated.
