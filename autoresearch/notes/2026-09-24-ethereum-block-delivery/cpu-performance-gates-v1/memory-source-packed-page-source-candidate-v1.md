## Cohesive implemented path

Ten existing first-protocol/columns/round/page-store/replay/page-protocol/binding adapters now select one shared `ForSchema` owner/equation implementation. Legacy B5SC exports, fixed/main recipe, schedules, ABI/channel and bit-file grammar remain unchanged. The distinct B5SR specialization enumerates only SHA and raw-record chunks, accepts a reader without any sibling/opening callback, and binds a distinct ABI and compact file magic. `Raw.Files` borrows the actual strict-RAM source writer files; no sibling-path source or full image owner is introduced.

The durable raw page encodes SHA raw64/state32 as96 bytes, input/RW/first-touch address/predecessor/value as12 bytes, and endpoint address/predecessor/full-u64-clock/value as20 bytes. Its independently admitted chunk kind chooses lengths; the file has no self-selected row tags. Encoding compares the fully restored witness and rejects every nonzero dropped cell or padding row. Loading reconstructs unused/tail cells as zero. Constant4KiB buffers cross record boundaries; exact file length, scope, exclusive synced publication and pinned SHA remain transport checks only. Compared with the former216-byte bit envelope per fully occupied row, operand bytes are2.25x smaller for SHA,18x for12-byte records,10.8x for endpoints. These are byte counts, not timing or proof performance claims.

`packed_sha_columns_v1` regenerates the original packed source/schedule/round/feed-forward SHA AIR columns directly, plus exact signed bitwise/range8_8 multiplicities. It includes original all-zero padding effects, checked fixed tails, and capture/main connector columns. No full core matrices or call tape are persisted. All private state/capture values remain commitment inputs, not checked host authority.

`packed_sha_replay_v1.ForBackend(B)` exposes `collect`, `persist`, `replay`, `Reader.take`, `Loaded.deinit`, and real retained-tree `lease`. Its independently expected Pin binds the exact raw page/geometry and SIX roots: raw-fixed, original raw-main, original core/table-fixed, original core/table-main, connector-fixed, capture-main. Replay recommits the two original raw roots, regenerates all core/capture matrices, and recommits/matches ALL remaining roots. It retains a single bounded resident page, guards live leases and owner mutation, and poisons collection after a failed partial page. A file hash cannot supply any root authority.

`packed_sha_proof_v1.ForBackend(B).prove(owner, admitted, plan, expected, limits)` uses the existing PCS/proving engine: seven components (four original SHA AIRs, two exact tables, same-original-main connector), one interaction tree, one composition and one FRI. `Proved` retains the bounded owner until export/deinit. `verifyOwned` consumes a decoded proof, independently reconstructs real CPU fixed roots/inventories/degree/config/transcript, and invokes the original fresh typed CPU verifier. It returns only `KernelVerified`, never a complete SourceReceipt or global receipt.

The seven precomposition trees plus composition make eight postcard trees. `packed_sha_codec_v1.encode/decode` independently derives all eight inventories, pins source/page/kernel IDs and six roots, enforces limits before allocation, and uses additive bounded `proof_preflight.ShapeFor(8)/validateFor(8)`. Legacy Shape/Shape5 parsers still use their unchanged paths. Dedicated kernel wire draws occur AFTER all six roots: both requesting sides alias original committed raw/capture inputs, so there is no adaptive copied arithmetic input in this kernel. The eventual Source9 semantic arithmetic graph needs its own arithmetic commitment before its separate binding challenge.

Raw pages: row_log1..12, at most4096 chunks/page,262144 pages and1Gi chunks; default512MiB raw owner heap and64MiB roster cap. Durable defaults:2MiB/file,16Mi loaded cells. Core recipe: at most8192 compressions/page and256Mi cells; integrated page budget defaults1GiB and includes raw owner plus regenerated cores/PCS. Proof interactions: at most256Mi cells. Strict codec defaults32MiB proof,33MiB artifact. Caps are admission maxima, not a measured assertion that every maximum-sized page fits the heap. The independent collector/receiver derive actual geometry and reject resource misses; product-level configuration still needs integration.
