The hidden scratch boundary is important: memory admission must include every simultaneous persistent prepared arena, each request arena, scan/lookup temporary buffers, FRI/quotient work, graph/module/global state, async allocations awaiting a completion event, and pinned host ingress/egress. `execution_cache` currently admits a persistent arena using available memory plus a 256 MiB reserve; that reserve is not a proof that another concurrent arena and all transient scratch fit. Pool free bytes and an enqueued free are not permission to reuse an in-flight allocation. Real overlap needs one aggregate reservation owner with exact per-context/arena leases before any prefetch launch.

There is no clean bounded overlap extension within the present ABI: no lane stream getter, dependency record/wait API, selected-device context constructor or per-device registry ownership exists, and AOT functions/graphs are bound to the sole context stream. The delivered patch rejects unsupported scheduling instead of representing these missing device operations as host queue metadata. Hardware overlap, geometry batching, completion/prefetch execution and multi-GPU residency remain implementation and qualification work.
