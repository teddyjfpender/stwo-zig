Concrete implementation

It keeps only canonical routing columns, graph IDs and exact counts; each transient graph and use scratch are released before the next chunk. Private input node IDs and multiplicities come from the original authoritative arithmetic use counter, not received descriptors. The planner also calls the authoritative arithmetic count implementation, caps all operation rows and signed wire mass, and gives every chunk a unique canonical `8,000,000+global_ordinal` circuit ID. Every unused/padded routing cell is zero.

`Binding.Component` opens exactly four real trees: original source fixed0 (15 columns), ORIGINAL source private main1 (1728), independently reconstructible routing fixed2 (3457), and interaction3 (3456). It never commits a copy of private source inputs and never aliases a new witness in place of old main openings. Every private bit is Boolean, every padded bit is zero, and paired wire(6) prefix equations emit exact `uses/(alpha tuple-z)` requests for the corresponding arithmetic circuit inputs. Two requests per plane retain degree3; bit/tail equations are degree2. Shifted openings belong only to prefix columns. Scalar point, scalar domain and SIMD equations share one generic algebra. Framework mask/domain remapping retains all original-tree masks and inventories.

Public claims are864 secure plane sums plus an independently matched u64 private-use census. Durable replay

`PageStore` streams the original Boolean source cells in column-major physical circle order as bit-packed bytes, binding exact page and original Pin identity in a64-byte header. Source log12 yields884,800 bytes/file instead of28,311,552 bytes of private M31 cells. This is proposal compression only; every loaded cell is restored exactly as M31. Unused byte bits and padded rows must be zero. Files are exact-length/hash/scope checked, synced and published by exclusive hardlink+directory fsync; no silent replacement. One4KiB codec buffer is used, with no complete raw file/image/input buffer.

`PageReplay.loadRecommitted` rebuilds original fixed rows, genuinely recommits BOTH original fixed and private main trees using the original first-round recipe/channel, and rejects either changed root. Only afterward does it publish the real FirstRound owner. The hard page allocator remains stable through immutable PCS leases. `Reader.take/Loaded.deinit` adds explicit one-page residency; reader teardown fails while a page is live, and page teardown preserves the residency token until all actual shared-tree references are released. `persist` requires the original owner/root/config/shape checks before file emission.
