B5SC source first-round lifecycle — unqualified source candidate

The equation kernels were independently qualified by the root agent (full source equation gate12/12; crypto parity in Debug and ReleaseFast). That qualifies the equations and graph construction, not any source proof. This candidate adds six new source files without changing those kernels or enabling a canonical proof route. Only parser formatting was run by this agent; no compiler, commitment, proof, guest, segment or device jobs were invoked.

Implemented path

* `FirstProtocol.init` derives the exact canonical chunk census from independently admitted full-image/public-input/first-touch/final pins. A page has actual circle row_log1..12; no virtual event domain. Plan, source identity, ABI, actual config, page index, first chunk and final tail are transcript-bound.
* `Columns` emits fixed15 (activity, exact u64 ordinals/kind/local ordinal/height/boundaries) and main1728. Main contains every private bit used by the existing equations: raw64 bytes, SHA state8 words, four full words, full u64 clock, and three32-byte routing/hash states. Fixed rows are independently reconstructible; padding has zero main and canonical fixed tail. Commitments are real CPU/backend PCS operations, not file SHA authority.
* `ForBackend.collectPage` commits fixed/main using bounded stable allocator ownership and borrowed streaming columns, returns actual roots, and poisons collection after partial failure. Only one page owner is resident; the Collector must outlive that owner. Owners may be released only after both wrapper leases AND real shared-tree references are gone. A moved consuming Scheme cannot leave the Budget allocator dangling. Local column SHA is an immutability guard only.
* `verifyFixedRoot` genuinely reconstructs and recommits fixed rows independently. `lease` uses the existing shared PCS tree API; independent proof channel and subsequent tree ownership are preserved. Actual commit/recommit/lease bodies are retained by the fixture root but never invoked by its tests.
* `seal` requires the complete contiguous exact page-root roster. `draw` replays the established Word challenges first, then binds the entire B5SC roster before drawing the9 internal source challenge pairs. `drawFromChannel` continues the same line for a future arithmetic proof transcript; its caller must first independently admit that roster.
* `admitPage` rebuilds actual existing B5SS admission with independent source pins, complete roster and exact config. `prepareChunk` reconstructs kindAt and private graph inputs from the retained main cells, and builds the qualified source equations under these new prechallenge roots. It enumerates all1728 original tree1 input bindings. It returns a candidate, never a verified source receipt.

Bounds

Every owned page allocation and PCS operation uses a stable hard512MiB budget. Private-cell cap16,777,216; chunk cap2^30; page cap262,144; canonical Pin roster cap64MiB. No whole-image/file/input owner is allocated. Source stream/circuit limits remain the independently admitted equation limits. Unsupported geometry/config/counts fail before page cell allocation. All source callbacks remain private witness providers.

Fixture scope

Eight named nonproving checks: exact source/plan/roots/config/page/roster/tail/caps and downgrade mutations; full roster challenge dependence with exact existing Word draws; every challenge allocation failure; bit-for-bit parity against the existing equation input writer including full u64 clock and high word/hash bits; exact canonical circle/tail and non-Boolean mutations; every column allocation failure; all5 real SHA chunks for empty files; actual CPU lifecycle body retention. Synthetic fixture roots are metadata proposals. There is no fake successful empty proof.

Use the existing arithmetic lowering Plan and exact use census, with a versioned source input bus and source page/chunk/bit ordinal; do not reuse native graph circuit IDs or native receipt authority.
