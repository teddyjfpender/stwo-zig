## Actual lifecycle

`block_v5_memory_source_unified_page_proof_v1.Context` owns the complete independently admitted raw/fold six-root rosters. `ForKind(.raw/.fold).ForBackend(Backend).prove` borrows the actual six-tree owner, materializes the original semantic graph and arithmetic columns, commits independently reconstructed semantic fixed/main trees, draws the dedicated PAGE relations, and invokes the original PCS/STARK implementation once with one aggregate component. `ForKind(...).verifyOwned` consumes owned proof vectors on every path, reconstructs the graph/routing/use counts and all fixed trees without private evaluations, reproduces the transcript, and freshly verifies all original equations. Its `VerifiedPage` proves one page and carries only that page's public source/indexed/fold sums.

The ten commitment inventories are source fixed/main, original hash-core-and-two-table fixed/main, original hash capture fixed/main, semantic fixed/main, interaction, and composition. Source and capture input suppliers alias their original committed cells. Exact mask union is necessary: exporting children separately would duplicate non-preprocessed main inventories. The aggregate preserves every original child's local view and mask, invokes the reviewed quotient polynomial extension when normalizing original degrees, and retains both segment/binary lowering lanes with distinct circuit IDs while committing segment rows.

Raw SHA uses the original four packed cores, original two table providers and capture connector. Fold BLAKE uses original G/XOR cores, signed counters including physical padding, the same two providers, and all 48 original compression boundary wires including discarded output words. Shared/default compression recipes are independently pinned before Source9 and constrained against complete private operands. Kernel/table/capture wire closure and semantic arithmetic/input wire closure must each be zero independently; they cannot cancel against each other or another page.
