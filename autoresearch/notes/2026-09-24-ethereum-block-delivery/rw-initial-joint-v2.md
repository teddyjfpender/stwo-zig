# Block-v2 RW initial source proof (2026-09-25)

`zig build test-block-rw-initial-joint-v2 -Doptimize=ReleaseFast` passes for three authenticated source cases with a fresh verifier. Each one-PCS proof contains typed BLAKE3 shared-path G/XOR/boundary/route/private/bridge components, the RW provider's universal byte-range and recursion-wire effects, and a separate quotient for its **positive nine-field initial relation**. The two nonzero fixture words are one ordinary RW word and one public-input word under a continuation snapshot root. A zero-query proof authenticates a different, absent address as zero under that same root. The third case proves a bounded dyadic subroot and independently recomposes it against the full continuation root.

The PCS commits fixed and main trees before deriving lookup challenges. B2SS-v3 seals the ordered first-round root roster; all components derive the same 47 universal and block transition/link/initial challenge bundle directly from that bound seal. Local PCS channels also mix their own tree roots for FRI/openings. The fresh verifier replays the relation draw and pins the reconstructed fixed preprocessing. In the sparse mode, every unselected frontier digest is a verifier-reconstructed fixed empty-subtree row; adding a hidden nonzero leaf causes the test to reject the roster. In the zero-query mode, the queried leaf is the fixed empty digest, typed parent hashes connect it to the admitted root, and AIR constraints force all four initial-value bytes to zero while the positive initial tuple remains active.

These are separate tiny source proofs, not full block timings. The zero-query path is sound but too expensive for 2.46 million mainnet zero first touches. The private complete-sparse mode now supports bounded dyadic sharding, but a 666,708-leaf mainnet image would still need roughly 163 source proofs and substantial hash work. A verifier-visible public nonzero image is the current block-scale fallback; the succinct path remains a complete-sparse source plus a proved ordered merge. Its global initial-bus claim cancellation against sorted-memory requests is still outstanding. The test's bound first-round roster contains its own fixed/main roots; production must bind the complete global roster of memory, range, execution and source roots into one shared seal before any relation draw. A detached serialized private-source receipt API is not yet present.

For the qualified three-segment fixture, the complete 150-nonzero-leaf continuation snapshot topology has 348 computed nodes, 49 frontier nodes, and 55,600 hash-component rows: 30,576 G, 8,736 XOR, 10,416 boundary, 150 bridge, 5,346 route, and 376 private-word. That is 26.16 times fewer rows than the 4,716 first-touch-key path plan (1,454,288 rows). This census is a topology/witness estimate, not a measured 150-leaf proof time; the small-fixture factor does not predict mainnet proof time.
