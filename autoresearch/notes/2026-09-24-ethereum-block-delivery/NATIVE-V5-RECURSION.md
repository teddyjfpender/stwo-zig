# Native-v5 recursive verifier seam

The new native-v5 path proves ordinary typed opcode and clock equations without per-leaf hash custody. Native-template protocol v2 replays the frozen B5SS universal challenge prefix in the local PCS channel, then absorbs template, instance and first roots. This makes the complete verifier transcript linear for recursive replay without changing the shared relation challenges.

The recursive adapter uses the same typed native equation recorder as the native verifier, native-only DEEP geometry, and the existing constrained FRI, Merkle, hash and transcript row machinery. It constrains native interaction claims plus public compensation to an exported open sum. It does not assert a local zero closure. The complete block receiver must still cancel all program, memory, lookup, precompile and public boundary terms using fresh global provider proofs under the same B5SS challenge bundle.

`block_v5_native_template_catalog_v1` admits an ordered record for each real leaf: ordinal, exact geometry digest, fixed root and template ID. This lets one SourceSeal admit varied geometries. It does not make different active counts reuse one native key: `isActive(log,n_rows)` remains in the native fixed tree.

The original recursive adapter remains deliberately specialized per instance. Both B5SS first roots are fixed boundary rows; B5SS digest, template/instance IDs, endpoint compensation and exported sum also affect its fixed circuit/key. It proves the correct native-v5 equation but does not yet provide reusable recursive setup. The new reusable route binds the full changing tuple through a verifier-owned public supply on `recursion_wire`, preserving the 23-slot roster. Its key binds only exact native geometry, circuit graphs, transcript/routing schedules and fixed capacity. B5SS/template/instance IDs, ordinal, both first roots, endpoint-dependent compensation and exported claim have no internal fixed provider. The independent parent admission mixes the full tuple and canonical public statement digest into its PCS transcript and recomputes the opposite public relation claim after parent challenges. Received bytes cannot select that tuple or setup.

`block_v5_execution_leaf_binding_v1.prepare` attaches the v5 span and fresh ordinary sidecar receipt to those native verifier rows. Its fresh leaf receiver requires an independent recursive key pin. The returned descriptor is suitable for exact-count forest construction only within a complete receiver that separately closes the global claims. SHA/Keccak/signer arithmetic uses a separate family-11 root authority; ordinary native roots do not contain those caller columns. Zero-ordinary segments still require their own admitted v5 branch.
