# Ethereum products

[`statement/`](statement/README.md) owns RV64 Ethereum request admission,
guest identity, proof orchestration, reception and recursion. It exposes
`stwo_ethereum_statement` and builds the Ethereum CUDA producer and CPU recursive
receiver. The product guide names the relevant targets and contract tests.

The [Ethereum guest guide](../../../guests/ethereum/README.md) owns the source
and build instructions for the ELF that the product consumes.
