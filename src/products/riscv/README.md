# RISC-V CLI products

This line owns the focused RV32IM zkVM [CPU](cpu/) and [Metal](metal/) CLIs,
their proof artifact and verification framing, and CSP tools.
Start with the [RV32IM build and test guide](../../frontends/riscv/README.md#build-test-and-run)
for build, prove and verify commands.

Library consumers use the [RISC-V frontend](../../frontends/riscv/README.md)
or its [CPU integration](../../integrations/riscv_cpu/README.md). RV64 block
statement workflows live in [Ethereum](../ethereum/README.md) and
[OP Stack](../opstack/README.md).
