# Native products

Native products prove built-in Stwo workloads directly. They own the
[examples library](examples/README.md), request and artifact handling, and the
[CPU](cpu/), [Metal](metal/) and [CUDA](cuda/) CLI adapters.

Use `stwo_native_examples` for the example AIRs and
[the Native quick start](../../../README.md#prove) for CPU prove and verify
commands. The [Native CUDA integration](../../integrations/native_cuda/README.md)
documents the staged resident adapters and their qualification scope.
