# OP Stack products

[`statement/`](statement/README.md) owns the RV64 OP guest ABI, public
statement, native CPU proof production and fresh reception. The module is
`stwo_opstack_statement` and the CLI is `stwo-opstack-native`.

See the statement guide for supported profiles and the end-to-end probe.
The [OP runbook](../../../tools/opstack/README.md) covers guest builds,
replay fixtures and the scope of retained benchmarks.
