# Inactive native2n Keccak prototype

This explicit standalone provider preserves the paired permutation and IO11
relation, with MAIN1925 / INTER3896 / FIXED32 and maximum residual degree three.
It is absent from the accepting combined-services roster and default provider.
The layout identity is mixed before roots and challenges by its fixture.

Two committed Boolean enables equal the existing round and IO selectors. Each
pair has one secure inverse constrained by `inverse*d0*d1=enable` and
`inverse*(1-enable)=0`. An enabled pole is impossible. A disabled inverse is
zero even at a pole and contributes no debt. A single circular prefix sums the
pair terms; the final odd IO pair uses one real denominator and a dummy1 whose
numerator weight is zero. The existing immutable geometry, call-span equations,
lookup tuples, positive masses and table arithmetic remain authoritative.

The shared direct authority retains the original active boundary bit gate for
legacy. This prototype removes that factor. The difference for bit v is
`boundary*(1-v)*((1-active)*v)`, a multiple of the unchanged padding residual.
Thus the permitted native witnesses agree. The prototype's bit residual is
cubic, each strict pair inverse is cubic, its enable guard is quadratic and its
single prefix is quadratic. Fixed selectors remain unrestricted polynomial
inputs at LDE/OODS points; there is no native-phase shortcut.

The runtime tradeoff is unfavorable for a memory-first default without further
evidence. It cuts permutation point-column arithmetic area by35.7%, but raises
committed source columns by28.6% and interactions by50.1%. The current legacy
provider already has bounded n-point cosets: scratch6158n M31 becomes7460n,
which increases peak scratch by21.1%. It does not halve peak allocation.
The q70/P26 five-call proof is24.4% larger than the existing triple control.
No whole-job speed or RSS improvement is claimed. Native interaction generation
is serial in this prototype; it is not a production interaction implementation.

Existing bounded legacy log17 truth instances are an independent control:
splitting an even call span preserves total permutation area while halving
per-proof source/coset allocations, at the cost of more proofs/openings and
small duplicated table requests. Neither this model nor a tiny fixture measures
whole-block peak. The qualified services receiver continues choosing its prior
4n implementation unless a separately qualified protocol binding activates a
new layout.
