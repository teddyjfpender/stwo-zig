# Complete finite positive pairing MAC12 physical experiment

This is an isolated source/physical experiment, not a VM delegation or production pairing acceptance path. It proves the complete four-pair source DAG under independently expected finite canonical inputs: G1 curve equations, four exact G2 subgroup computations, all87 preparation lines per pair, shared Miller accumulator, positive residue certificate,1,438 canonical private hints and1,460 immutable zero/one assertions. The residue consumes the actual Miller output IDs; there is no independently claimed public z. Infinity/general malformed-input/fallback policy, dynamic request shape, VM/RAM/Wire and recursive integration remain open.

The arithmetic source normalizes31,996 original writers to32,533 concrete MAC12 rows, including fresh SSA temporaries and source-literal-only folding. All25 input ports count even when their fixed coefficient is zero; all endpoint assertions remain negative unit consumers. Source-owned fanout/IDs cover814,785 reads/assertions. The private hints are canonical physical writers, not trusted host-validity bits. The public54-field frontier derives from pinned input/constant authority, independently of actual witness values.

This does not stop at a host canonical-input check and does not use an honest shadow GKR reader.
