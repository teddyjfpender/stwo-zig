# Serialized sponge local-GKR fragment (closed)

This candidate reuses the existing checkpointed OM31 GKR prover, bounded wire
codec, terminal Eq/prefix witness and pure-P2 transcript. It introduces source
roles; it does not alias classic CPU Frame origins. Source construction fills
each narrow MAIN once, computes range/AND multiplicities from those same cells,
and streams facts from column-major MAIN. No dense denominator plane is retained.

The eight instances are descriptor, state word, permutation header, message word,
absorption lane, U16 provider, U8 provider and AND provider. Geometry is derived
from independently expected call/permutation counts; table logs16/8/16 are fixed.
The five bridge roles model467 opening columns; independent standalone providers
add56. CPU integration can share existing tables only through a qualified common
challenge/closure authority, which is not implemented here.

OWNER, AND, U16 and U8 use separately labeled independent challenges drawn after
all MAIN commitments. One joint rational sum closes the internal debts. Equal
and opposite *field weights* from different namespaces are not deterministic
cancellation: their independent denominators must also match. The gate rejects
that attempted cross-namespace cancellation. Each role's terminal marginals are
bound independently; summing terminal errors cannot replace those bindings.

The original CPU ECALL OWNER debt remains an explicit external boundary. Exact
expected pointer/epoch/tick/tag records, supplied independently of descriptor
MAIN, are canonically SHA-framed into the child scope and recompute its expected
OWNER claim. RAM and KIO are still global physical obligations. No fragment API
returns accepted execution. Calling an unbound child verifier only returns
pending terminal equations, not an accepting physical proof.
