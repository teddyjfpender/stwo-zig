# Serialized sponge local-GKR fragment (closed)

This candidate reuses the existing checkpointed OM31 GKR prover, bounded wire
codec, terminal Eq/prefix witness and pure-P2 transcript. It introduces source
roles; it does not alias classic CPU Frame origins. Source construction fills
each narrow MAIN once, computes range/AND multiplicities from those same cells,
and streams facts from column-major MAIN. No dense denominator plane is retained.

The eight instances are descriptor, state word, permutation header, message word,
absorption lane, U16 provider, U8 provider and AND provider. Geometry is derived
from independently expected call/permutation counts; table logs16/8/16 are fixed.
The five bridge roles model467 opening columns; independent standalone providers
add56. CPU integration can share existing tables only through a qualified common
challenge/closure authority, which is not implemented here.

OWNER, AND, U16 and U8 use separately labeled independent challenges drawn after
all MAIN commitments. One joint rational sum closes the internal debts. Equal
and opposite *field weights* from different namespaces are not deterministic
cancellation: their independent denominators must also match. The gate rejects
that attempted cross-namespace cancellation. Each role's terminal marginals are
bound independently; summing terminal errors cannot replace those bindings.

The original CPU ECALL OWNER debt remains an explicit external boundary. Exact
expected pointer/epoch/tick/tag records, supplied independently of descriptor
MAIN, are canonically SHA-framed into the child scope and recompute its expected
OWNER claim. RAM and KIO are still global physical obligations. No fragment API
returns accepted execution. Calling an unbound child verifier only returns
pending terminal equations, not an accepting physical proof.

Qualification now includes a complete eight-component physical PCS proof plus
checkpointed GKR and a fresh receiver. The fixture is one fresh empty call, one
permutation; it is a source/component gate, not an execution proof or speed
comparison. Native proof409,328 bytes plus local GKR28,244 bytes; requested peak
148,002,164 bytes under a2GiB allocator cap. The retained proof SHA256 is
`7b664a04002cb4f5321614a5366474822ca820ebe59424c7bedfd58959b70b11`.
The recorded producer phase was0.996s without a controlled matched baseline.

The receiver rebuilds the fixed tree/key and each component from independent
source geometry, parses/reverifies GKR and reconstructs its terminal bindings;
it does not trust prover component objects. Wrong independent CPU boundaries,
receipt limb9, forged terminal marginals, same-fixed-geometry firstID changes,
and balanced physical RAM claim changes reject. An actual descriptor MAIN plus
opposed range multiplicity false witness cannot close the local GKR argument.
All recorded equation-IR residuals are checked to have degree at most3 before
key construction. A witness-only cache change preserves the complete proof
bytes and immutable semantic identity.

Two FIRST-row selectors were required for the global prefixes of message/lane
roles: the physical five-role width is467, not the original source projection465.
Standalone providers add56, for523 total columns and745 OODS samples including
the8-column composition. These are source-owned independently sized tables;
sharing them with CPU tables remains a separate qualified integration step.

Production CPU/global inventory integration, exact OWNER coverage, source-family
recursion and representative real-height cost measurements remain pending.
No fragment API accepts an execution. Persisted artifacts and stage data are in
`rv64-proof-artifacts/20261109/opstack-cpu/serialized-sponge-fragment-v1`.

The intended label remains “128-bit security target under documented assumptions”;
`security_qualified=false`. A composed certificate is not claimed. For a bounded
review, count all positive and negative requests/provider multiplicities in each
namespace; geometry bounds their integer total below the M31 characteristic.
Canonical table roots are source-owned; malicious multiplicities are field cells,
whose residues must equal the bounded request multiplicities if the rational
identity holds. The joint rational identity/pole union is bounded over OM31's
cardinality, not M31. The review must additionally include namespace collision,
GKR batch/layer/round mixing, Eq/terminal late-binding and PCS/FRI union terms,
plus all P2/hash/transcript calls under the full parent profile. Independent
namespace draws and a large extension do not alone certify the whole protocol.

## Detached flavor and tiny CPU frontier

The new explicit `Geometry.detached=true` selects typed role
`detached_descriptor` (MAIN74, local queries46, INTER64), a distinct source domain,
wire magic `OPSDETG1`, fixed/key identity and request statement. Its public native
APIs use `DetachedScope`, `proveDetachedUnboundWithOptions`,
`verifyDetachedPending`, and `Key.statementDetached`. There is no Boundary,
pointer-list or boundary digest in this flavor. The source suppresses the named
CPU ECALL slot at compile time; it does not blindly skip an emitted tuple.
Internal state/header/window/carry/range/AND debts close to zero. The old boundary
flavor retains its exact semantic identity and409,328-byte proof SHA control.

The detached descriptor instead consumes shared Wire35 kind0x53504746 with fields
`[kind, CPUordinal, complete OWNER19, fourteen zeros]`. CPUordinal is derived as
its authenticated call epoch minus one. The CPU-side source frontier has8 MAIN,
3 FIXED and24 modeled INTER columns (one16-column local-GKR binding plus one
8-column implicit-inverse Wire prefix),3 local queries and7 MAIN constraints.
Its OWNER consumer has Boolean unit weight and the full original opcode, service
tag,64-bit pointer, epoch and24-bit tick. Tick limbs are explicitly U16/U8;
pointer limbs inherit canonicality from the existing CPU OWNER provider.
Public/source policy and AIR both enforce epoch=CPUordinal+1, with ordinal<256.
This is a new-flavor contract; an incompatible epoch convention must reject it.

The Wire tuple is injective: no coordinate is reduced, hashed or omitted. A
compile-time check rejects collision with the registered packet bridge kinds
(secp, SHA, arith, curves and Miller). The detached ordinal derives from the same
OWNER epoch, and every other Wire namespace has a different fixed first field.
Frontier rows are independently sized by call count, not CPU retirements. The
CPU source-width model is5,896−2,513+35=3,418 columns. This is a model, not a
measured CPU or root speedup.

The detached fragment now physically qualifies under the same2GiB cap:
414,476-byte native proof +28,244-byte GKR, SHA
`bc6ef41f1afea46d179b89917c40497983db127f301a38f3ac6f341eb4b32996`.
Requested peak148,010,548 bytes; the0.998s producer phase is an uncontrolled
one-call qualification. Its shared Wire claim equals the negative claim of an
independently constructed, epoch/ordinal-bound frontier tuple. Wrong Wire claim,
wrong mode/magic, same-fixed-root flavor substitution and firstID changes reject.
Legacy mode refuses any nonzero Wire claim even though its old transcript stays
byte-identical. All recorded detached equations also pass the degree3 IR gate.
This is not yet a proof of an actual CPU/frontier/detached execution join.

Production join gates still required:

- A closed new CPU flavor replaces the two old sponge slots with the frontier,
  includes its exact local OWNER/range facts and binds its public counts/epoch/
  ordinal. Existing Frame origins and protected AIR authority stay unchanged.
- Stage1 commits all CPU/frontier/detached MAIN and table multiplicities before
  the common manifest draws RAM/KIO/Wire. Calls batch independently across CPU
  shards; exact per-CPU call counts and global permutation-ID spans must match.
- A fresh complete receiver derives the new flavor/key/geometry independently,
  authenticates every local terminal and physical claim, and closes global
  RAM/KIO/Wire. Missing/duplicate/cross-CPU calls, changed ordinal/epoch/tag,
  message/state aliases and terminal-output mutations require physical joins.
- New source-owned recursive statement/capture/leaf and R6 topology/receiver
  admission must qualify. Native source width is not a recursive timing result.

`sourceSuite.sponge0` and all production admission remain closed.
