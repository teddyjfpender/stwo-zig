# tensor-frontend Lean proofs

Zero-dependency Lean 4 (v4.35.0, core only) proofs for the stwo-zig tensor
frontend. What is proven, what is assumed and what is not covered:
`design/tensor-frontend/lean.md`.

    scripts/check.sh     # lake build + axiom audit + security re-check
    # or, from src/tensor:  zig build lean

Modules: `Poly` (root bound), `Sumcheck`, `LogUp`, `Kernel` (requant / no-wrap /
softmax division), `Security` (union bound, exact dyadic checker),
`Data/Toy20Johnson` (generated by `scripts/terms_to_lean.py` from
`scripts/toy20_johnson_terms.tsv`).
