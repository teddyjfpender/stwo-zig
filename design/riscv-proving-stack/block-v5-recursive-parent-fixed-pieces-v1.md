# Capture-free original parent fixed compiler pieces

This candidate separates fixed setup from successful proof capture. It changes no original transcript grammar or verifier equations and enables no canonical selection. It has not run a compiler, test, proof or benchmark on the agent side. The result is explicitly **partial fixed setup**, not a derived complete key or standalone block authority.

`recursive_parent_shape_v1.Shape` derives the original parent column placements, normalized quotient split, exact previous/current sample order, composition columns, extended domains, query count and FRI widths from admitted logs/config. `validateAgainst` rebuilds those profiles independently; changing a profile and recomputing its local seal is insufficient. It contains no claims, sample assignments, nonce, challenge, query values or verified receipt.

The new closed-node `ShapeAdmission` is a separate fixed-only type. It takes the independent `Bus.Owner` policy and retains the original public-frame recipe and coordinates. It deliberately lacks `expected_id`, `admitRoot` and `mixClaims`: the actual core proof verifier cannot treat it as successful proof admission. Public policy and the borrowed owner must remain immutable throughout synchronous construction. The caller must retain that owner until construction completes.

`open_parent_composition_v2.compileShape` now owns the single original equation body. It authenticates the shipped direct and relation programs, derives component/table placements, emits every original quotient/claim/public-supply/span equation, and returns circuit plus input-source schema. The existing live `prepare` still validates the genuine capture, public-input custody, original component masks, composition masks, sample count and claim count before supplying values and evaluating this same circuit. No alternative AIR or dummy capture is made.

The DEEP and FRI pieces call `pcs_deep_circuit.build` and `fri_verifier_circuit.build` with the original shape profiles. The fixed arithmetic wrapper calls the original `arithmetic_fusion_rows.materializeFixed`, requiring a complete original reference with both graphs present in the selected mode. It supplies no graph evaluations.

The fixed transcript calls the original `Plan.initCompact` and its trusted bounded emitters. Public frames use the same generic byte-routing adapter as the live source. Private payload buffers carry lengths only and enter exclusively trusted emission; no native channel or private hash evaluation occurs. Every private frame has original routed suppliers, every secure draw exports its original semantic role, and query count/PoW/domain/FRI framing remain exact. Constant protocol tags are the only constant private-prefix frames. The bounded fixed plan is compared against a separate original native-channel operation oracle containing nonzero payloads and genuine challenge/query draws; this oracle is not a STARK acceptance fixture.

The fixed path piece reuses `blake3_stark_paths.Builder` and the original lifted-leaf, Merkle group, ordinal shared-root and two-level-frontier trusted emitters. All direction endpoints come from the original DEEP query-bit binding graph. Count-only arrays describe widths/depths, cannot become accepted proof paths, and are never passed to live root agreement. The live path emitter is unchanged except that its existing trusted count branch can now retain the same fixed metadata into a supplied destination. Query multiplicity changes are restored on failure. Fixed artifact owners retain the exact SharedHostBudget allocator lease through final destruction.

`recursive_parent_fixed_pieces_v1.Owned` composes these actual partial emitters without original proof files or a `Verified` argument. Its `complete_fixed_setup` and `complete_block_authority` are both false. Its emitted codegen wrapper also retains the actual original live producer/receiver paths, without invoking them in the pure tests.

## Exact remaining ports before complete expected-key derivation

1. `blake3_projection_links.buildMode` and `blake3_opening_inputs.Builder.initMode/trace/friGroup/finish`: expose fixed-only projection, field-byte, pack, readonly rank/last and adapter schedules from admitted column logs plus original DEEP/FRI bindings. Original private sorting and consistency equations remain on the live path. Fixed-only construction must preserve exact source ordinals and uses, rather than use synthetic queried values or a fake capture.
2. `blake3_native_payload_links`, sample/challenge/terminal/query/root bridges and open-parent public-input links: port their original fixed routing from the compiled input schemas, transcript exports, original endpoint descriptors and query path multiplicities. These are required cohorts; hash metadata alone cannot form a complete parent key.
3. `blake3_native_parent_rows.prepareMode`, native PCS fusion and selector/input inventory: add a fixed-only roster path using the original fusion matching/exports and one shared row-order recipe. It must include original dot4/native fusion routing and every boundary source, not only the residual DEEP/FRI DAG rows.
4. `blake3_g_partition` and `blake3_execution_parent_proof.deriveKeyWithProfile`: share the exact fixed partition geometry and original preprocessed PCS/table commitment without main columns. Context IDs must equal the actual live compile/namespace/transcript identities. This candidate does not manufacture that identity from host metadata or accept a supplied root key.

The version5 closure also intentionally fixes instance public supplier coordinates. Native main roots/open sums, true register/program compensation and public input-root request coordinates must become authenticated main suppliers before claiming reusable geometry. Preserve the original native main-root/public-claim/global compensation equations when doing that conversion. Independently reconstructed geometry does not itself establish those authentication equations or complete source/terminal/provider coverage.
