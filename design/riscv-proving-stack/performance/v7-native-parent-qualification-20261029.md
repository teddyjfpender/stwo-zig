# V7 native original verifier and detached recursive parent

The exact native execution, partitioned lookup projections and optional packed
RAM-access equations now compile under the v7 epoch without constructing a v5
source seal or accepting legacy admission. Original verifier capture copies the
physical claims; independently constructed PCS geometry owns its statement and
uses the original component masks, degrees and quotient split.

The focused ReleaseSafe gate passes 10 tests. Its actual RV32 cases cover both
four-commitment/no-access and five-commitment/access originals. Original proofs
are encoded and freshly verified, then the original proof and producer are
destroyed before composition, DEEP, FRI and recursive preparation.

| Three instructions, one ordinary RAM access | 129,556 | 13,266 |

These small cases qualify the lifecycle; they do not predict block time.
Security is diagnostic q8/PoW0 for the original and parent. No canonical root
or full Ethereum result is established here.

The original transcript encoder is shared with its statement recorder. The
53-pair epoch emits its interval challenge as two separate single draws, exactly
like the original channel. The test compares every exported scalar with actual
epoch output, as well as comparing independent/live fixed transcript plans.
Final-channel equality alone would not catch a draw-consumption error followed
by a counter-resetting mix.

Independent fixed rows match every live row, public wire, namespace and key.
The detached receiver recomputes the native fixed root, reconstructs canonical
public operands and verifies the encoded parent after parent producer rows are
released. Compensated physical-claim changes, altered root offsets and changed
expected keys reject. Returned native, register, program, lookup and memory
claims remain **open** until every source/provider closes in the final root.

The production join can consume `block_v7_native_preparation_v1.Prepared` rows,
public wires and canonical values directly. These standalone parent proofs are
qualification fixtures; they do not require an extra per-family proving stage
before mixed aggregation.
