# Full-u64 original child bridge v1

This additive source route preserves the actual native/capacity/fused/caller leaf receivers and their original proof transcripts. It does not widen legacy H or compact proof grammar. It is source engineering pending the parent-owned compiler gates; no proof, segment, device or benchmark execution is claimed.

The inherited cutoff is explicit in `block_v5_open_parent_public_bus_v1.validateSpanBound`: indexes/counts and first/last cycles must be below `2^30`. Its `spanWords` then represents a span as six u32 words, and several old hierarchy normalizers store those words as scalar M31 coordinates. Removing the check alone would introduce truncation or field wrap. Original `block_v5_native_public_admission_v1.Context`, `block_v5_pc_clock_span_v1.leaf`, and the capacity leaf fresh receiver already validate full-u64 endpoints. The original span checker remains unchanged and rejects wide inputs.

`block_v5_wide_original_child_source_v1.ForSubtype` selects an original typed stack at compile time. It independently checks Prepared, exact physical family/index/instance/roots, source seal, recipe, original key and schedule. `verify` invokes the unchanged actual `Definitions.verify` once and retains its core capture. Native arithmetic spans must agree with a fresh independent `Span.leaf` reconstruction. Fused/caller sources have no fabricated native span. `Source.init` alone supplies public admission normalization and is never proof authority.

The source clones small original word/felt frames, retains the shared allocator owner, and decodes cells lazily with binary search. `mix` and `replayPublic` reproduce only the original admission. Clock extension bytes never enter that original proof channel. `Original.Admission` forwards the original claim framing/config/root/public closure and leaves `pc_clock_children` empty. `planOriginal` invokes the full existing symbolic State verifier, including original composition, DEEP/FRI, Merkle paths and transcript checks. The six-word adjacency kernel is deliberately absent from that route.

The separate `block_v5_wide_native_public_values_v1` defines the new **B5WP** enclosing public grammar. It reconstructs all original PublicData and full clocks from independently admitted native Prepared and pin. It accepts an independent Source rather than a host-accepted sibling receipt, so a standalone upper receiver can reconstruct its public inputs without trusting proof-carried spans. The original instance and B5PD admission remain mandatory. Public input is borrowed once; raw preimage metadata is cloned under explicit extent/cell caps. Source and values owners retain exact shared allocator leases through teardown; ordinary stack/framework memory is outside those counters.

The new grammar includes the original key/public identity/seal, original admission bytes, independently derived B5PD bytes, exact raw public fields, and count/carry coordinates. `originalDigest`, `expectedDigest`, `firstCycle`, `lastCycle`, `clock`, and `auxFirst` name exact byte supplies. Full cycles use two little-endian u32 cells each; no clock is reduced to M31. The new root receiver must reconstruct every field from the independent typed policy. Dynamic private public-data hashing/decoding is not claimed: this is deterministic public-input derivation checked by the final receiver.

`block_v5_wide_native_public_graph_v1.prepare` derives 96 exact cell/byte inputs and actual symbolic equations. It equates the original B5PD digest bytes with the independently reconstructed public digest, constrains `steps + 1 = clock`, and constrains `first_cycle + steps = last_cycle`. Four 16-bit limbs and Boolean carries give exact integer interpretation, including high-u64 clocks and the final `u64.max` single-cycle case. Its graph sources request the same new-parent public cells that the final verifier reconstructs. Generic `record` is an equation fixture helper and grants no child or root authority.

`block_v5_reusable_wide_native_public_protocol_v1.ForSubtype` supplies distinct B5WK key identity, B5WP public input, B5WQ claim framing, exact schedule/source recipe and original recursive security checks. It permits original child cells/packed terms and new public byte cells only; legacy span/output kinds reject. This protocol must be paired with the actual same-parent preparation that joins full original verifier rows and this graph, then independently trusted setup. A metadata-only adapter does not make a wide proof.

The actual `wide_native_public_preparation_v1.ForSubtype.prepare` now joins the original verifier rows and the 96-input graph in the same parent, using shared `scoped_child_verifier_rows_v1` and admitted graph attachment. `wide_native_public_stage_v1.ForSubtype(Backend, subtype).publish` verifies the original proof, prepares both cohorts, compares independently admitted full new-key geometry/schedule, proves that parent and runs its genuine final receiver once. `wide_native_public_receiver_v1.ForSubtype.verify` independently reconstructs original Source and B5WP fields and verifies the new parent itself; it does not require a host original-proof acceptance token. Original typed policy owners must outlive these borrowers. The final receiver pairs its owned source/policy/public view, and retains shared allocator custody through control-node destruction. Durable artifacts retain the supplied allocator owner until their last bytes/schedule release. These actual bodies are source implemented and retained in the gate root; no successful proof execution is claimed. Original source/image/census and whole-block completeness obligations remain open even after local clock equations close. No canonical default is selected.

The first security batch intentionally includes instance/index/seal in the new setup context. It therefore does not claim cross-execution setup reuse even when rows happen to have the same shape. A later independently qualified fixed-template extraction would be required to remove those dynamic pins. Eight named pure fixtures cover original transcript identity, lazy boundaries, extent rejection, allocation rollback, full-u64 count arithmetic, high-limb/carry/digest/count faults, legacy rejection, and equal-byte source substitution. The fixtures produce no positive cryptographic child or parent.
