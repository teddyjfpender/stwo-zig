## Explicit input binding gap

`input_digest_link_proved` is false. The original capacity-native public bus exports B5PD, not a separately proved input-root claim. This batch constrains the original B5PD byte equality and independently recomputes B5PD from the expected whole input in fresh public admission. It does not prove an in-circuit B5PD-to-input-root factoring bridge. The digest recipe alone does not close that obligation. Complete admission fails with `WidePublicGlobalSourceClosureUnavailable`.

The original `publicDigest` cannot reuse a common input *prefix* compression context. It first absorbs B5PD/version, PC/clock, initial/final/last-clock register vectors, root presence and three roots, completion and IO metadata. Each invocation resets the BLAKE3 hash through the existing frame format. The shared input invocation then hashes exactly `PROTOCOL_ID || words_tag || incoming_window_digest[32] || LE64(word_count) || LE32(input_words)`. Output `(address,value,clock)` invocations follow it. The incoming digest varies per window before the shared input, so resuming one shared chaining value or substituting `hash(input_root)` changes original bytes.

A faithful future factoring path can share authenticated BLAKE3 **tree chunks**, rather than a sequential prefix CV. The original words frame has a 67-byte header; its first 1024-byte chunk contains the window-dependent header and the first 957 raw input bytes. Later chunks begin at input byte957 (word239, byte1), have common fixed chunk counters starting at1 and identical payloads for the same job length. A genuine input/source proof could authenticate those exact tail chunk/subtree CVs once; each window would still prove its original first chunk, exact counter/CHUNK_START/CHUNK_END flags, chunk/tree length, final root-output flags and output-frame suffix. Short inputs/tails, non-power-of-two trees and empty frames need exact cases. The current shared Frame.write/FrameHash witnesses have no admitted external chunk-subtree frontier interface, so this remains source work, not an implemented reuse or receipt. A versioned original input-root export is an alternative requiring a real AIR/transcript change, not metadata.

## Ownership and remaining integration

The input/job owners are explicitly retained. Original Prepared/key/schedule/shape/coverage policies remain immutable borrows and must outlive every stage, fresh receipt and higher reader. The receiver control node stays heap-stable. Deinitialization frees captures, metadata, terms and schedules before the last shared-budget lease is released. Parent preparation and stage allocations use bounded SharedHostBudget owners; this is heap admission, not RSS enforcement.

The candidate includes scalar-versus-original public arithmetic oracle fixtures, symbolic graph/OOM cleanup, high clock/count/carry/x0/sign mutations, exact bounded range and large-input descriptor tests, and cached-input owner mutation/retain/failure tests. It still requires root-owned semantic/body/test qualification. Actual compact upper policy/source selection, exact full coverage, provider/global residual closure, input factoring proof and original source authentication remain OPEN. Per-range contexts currently retain dynamic instance/namespace identity; cross-instance setup reuse is not claimed.
