# Exact heterogeneous hierarchy, open v1

This isolated route supplies genuine typed parent nodes for more than 32 native spans. It does not select a canonical driver, execute proofs, authenticate source descriptors, or issue `ClosedBlock`. The existing flat heterogeneous source remains unchanged and independently qualified.

`HierarchyPlan.Plan` borrows the original independently admitted `Full.Policy` and exact `Coverage.Plan`. It checks every physical leaf and intermediate node has exactly one incoming tree edge except the root, child ranges are contiguous, all eight kind censuses match, and tails are carried without adding padded proofs. Native arithmetic alone supplies PC/clock spans. Provider-only nodes carry `null`, including in their transcript and public supply. Pair and quartet nodes have two through four actual children.

`HierarchyStage.ForBackend(B).publish(backing, plan, node_admissions, loader, limits, sink)` reloads original bytes for each exact `Coverage.Ref`. Leaves use the actual original typed `Expected.verify`; nodes use the original parent STARK verifier under the independently chosen hierarchy admission. At most four owned captures are live during one node preparation. It builds original `State.plan` verifier rows, derives real geometry, requires equality with the independent node key and public schedule, produces original parent proof bytes, and freshly verifies them before publishing. A one-leaf topology forwards its freshly verified original typed leaf; it never creates a dummy parent. Sink success transfers bytes and schedule; all error paths retain and free them. Detached receivers use `HierarchyReceiver.verify` with independent `Protocol.Admission`, never key or export proposals from the proof envelope.

Every forwarded descendant cell has an actual equation between its lower child's authenticated original transcript byte and the current node's public-export byte. These are separate graph inputs and exact `recursion_wire` requests with lowering-derived use counts. The graph enters the same original arithmetic/opening/boundary AIR rows and injective namespaces as the original child verifier. Cell values remain canonical bytes because both sides come from independently normalized original frame values; byte-to-u32 span lifting is bounded by the admitted span authority. Intermediate native-span summaries also request the original lower-node transcript bytes, then constrain index/count continuity, clock+1, PC continuity, total count, and initial/final boundaries. Host `Span.merge` is admission and is not the only adjacency check. Native/caller arithmetic-to-fused pairing selects original root coordinates and is constrained at nodes containing both descendants. All original DEEP/FRI/Merkle/PoW and recursive public claims remain present.

Keys, instance framing, claim framing, hierarchy coordinate schedules, source exports and graph context use distinct versioned domains (`B5TK`, `B5TI`, `B5TP`, `B5TQ`, `B5HN`, `B5HY`, `B5HE`). The public source circuit is 4,200,014 and graph starts at 4,200,015 before injective relocation. Legacy heterogeneous bytes cannot be relabeled. Node policy contains the actual original descendant source framing, exact full coverage identity, recipe/seal, independent keys and schedules. Transported metadata is only a proposal.

The first implementation deliberately retains full original descendant frames. A root's nested source framing can occupy O(n log n) cells; independent source policies for every node can occupy O(n log² n) cells. Each exported census is exact, not rounded. `Plan.Limits` caps leaves, nodes, per-node exports and total exported cells. Stage admission counts the actual transcript words of every node through its real `Admission.mix` and rejects over `max_total_source_cells`; each normalized source also rejects over `MAX_CELLS`. The stage's captures/rows/proofs use an explicit shared byte budget; borrowed independent policy owners remain separately charged to their constructor. This is a bounded correctness route and is not the intended canonical performance architecture.

Eight named nonproving checks cover 67 native leaves plus eight providers in exact 75-leaf pair/quartet trees, single-leaf absence, forward references/caps, allocation failures, byte/span graph mutations, provider span absence, schedule relabeling, and original row equations plus exact tuple closure. The retained-body marker addresses the actual nine original leaf receivers and hierarchy preparation/prover/fresh receiver. No STARK, guest, segment, benchmark or device run has been executed by the author. Root/filter: `src/frontends/riscv/block_v5_heterogeneous_hierarchy_test_root.zig`, `heterogeneous hierarchy:`. Both independent policy runners are required and pinned in the source candidate.

Production integration still requires an independently reconstructed node-template/source policy, typed durable node transport, canonical driver dispatch, actual source/public/terminal authorities, and semantically complete scoped aggregate mapping. The already authored flat scoped aggregate wrapper cannot be passed to this hierarchy by relabeling children; a hierarchy mapping must select the genuinely forwarded cells. These obligations stay open.

The next performance batch should replace complete descendant framing with typed scoped summaries whose export equations read the original lower-byte inputs. Higher nodes must merge actual independently covered execution/window/group coordinates, with field-safe group boundaries and exact recipe/source pairing. A host sum, digest or coverage completion token is insufficient. That smaller export recipe will require separate admission and equation qualification before canonical selection.
