# B5IR/v1 bounded original input-request forest

This is a source candidate, with no compiler, proof, device or segment execution
by its author. It extends the qualified B5WM/v2 consumer and once-per-job tail
provider with actual bounded recursive parent producers and fresh receivers.
It does not activate the canonical CPU driver or establish complete source or
block authority.

## Original proof authority and topology

`block_v5_input_request_forest_plan_v1.derive` independently derives contiguous
leaf ranges from the original job window census. Each genuine WM/v2 leaf covers
1–4 windows. Interior nodes consume at most four original leaves or prior node
proofs; a partial group remains exact rather than rounded. All indices, counts
and physical leaf multiplicities are retained. Every leaf and nonroot node has
exactly one parent. A final node verifies one original tail-provider proof and
one summary child, at the unique common ancestor of every consumer. The empty
job is rejected; the existing typed empty-job path remains separate.

Original leaf, carrier, node key and wire schedule policies are independently
supplied, never read from a proof envelope or manifest. Node keys use version4
of the shared public-parent protocol, B5IR/v1 public framing and the new source
authority. Original native/WM/provider transcript bytes remain unchanged.

## Actual equations and production bodies

The node public statement contains bounded original input root, exact word
length, first239 input words and canonical original subtree CVs, plus exact
window range, physical consumer count and full-u64 clock endpoints. It carries
whole-job coverage/seal and independently derived topology identities.
Descendant public frames are not replayed into this summary.

`preparation.prepare` embeds each genuine typed child verifier through the
original `scoped_child_verifier_rows.prepare` machinery. It then attaches
`input_request_forest_graph` to those same parent rows using the original
admitted graph lowering. Every root/length/prefix/CV byte requests original
child public cells and equals an actual current-parent public cell. Range
adjacency and count/leaf conservation are equations. Eight byte coordinates
per clock feed the existing exact carry equations, including rejection of u64
overflow. The root additionally connects every input byte request to the
original provider cells. No host sum or verification receipt replaces these
constraints. Counts are admitted below2^30 to avoid field aliasing.

`Stage.ForBackend(Cpu).publish` fresh-verifies the selected original proofs,
derives real rows/key, compares the entire independently expected geometry and
schedule, proves the original parent AIR and fresh-verifies the result.
`Run.ForBackend(Cpu).run` actually invokes this producer in topological order.
It loads a bounded cohort, frees its bytes after publication, and loads the
carrier only for the final node. All node template identities are admitted
before any loader or publication. File length is checked before allocation;
SHA/length pins are transport selectors only. Publication is exclusive. On
failure, only files created by that invocation are removed. Sinks consume the
output only on success; construction and sink errors release output ownership.

The CPU facade `block_v5_cpu_input_request_forest_v1.publish` selects this real
path with a typed `Selection`; missing independent policy is an explicit error.
There is no old H conversion or fallback. `Result.verifyRoot` reads bounded
bytes and invokes the actual root-only receiver. A fresh root `Source` exposes
its original compact byte coordinates, census and full clocks for a further
typed parent; it does not manufacture provider clocks or compensation claims.

## Canonical integration remaining

The actual canonical Driver is not changed. Its caller must first construct a
stable independently admitted WM/v2 leaf catalog and original node template
recipes, retain their Prepared/key/schedule owners through all durable readers,
and install the explicit typed Selection/Loader after its original job policy
admission. `Plan.Owned` retains the expected job/input owner but borrows original
leaf policies; `Result` likewise borrows the Plan and node recipes. This is an
explicit lifetime prerequisite, not an owned standalone policy loader.
Received files cannot bootstrap these expected recipes. Per-node independent
setup reconstruction and a durable owner/loader remain the concrete driver
switch prerequisites.

This input root does not export/close all per-window register/program or scoped
compensation claims. The upper compact route must consume genuine WM exports
or a distinct proved scoped summary with exact normative source selectors.
Original source/global/provider obligations remain OPEN. No metadata bit,
manifest, host digest, receipt or old compact six-word span grants closure.

WM/v2 already replaces the original B5PD full-input AIR construction with its
original prefix/chunk-frontier fold. This forest makes that provider link reach
all consumers without embedding the same provider as a child of every lower
root. Host original public-policy validation/B5PD reconstruction still occurs;
forest validation currently reconstructs original descriptors, and child-term
lookup can revisit descendant public descriptors. Those remaining host costs
are explicit; this candidate is not an end-to-end speed or linear-host-cost
claim. Nor is it a successful proof, peak-RSS or GPU qualification.
