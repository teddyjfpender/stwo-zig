# Bounded original-input consumers and local carrier ancestor

This source candidate selects a distinct B5WM/v2 parent. The original native
child proof/channel is unchanged. The original B5WM/v1 wrappers retain their
public APIs and version1 grammar through shared typed kernels. Setup identities
pin those shared kernel bytes, so source-derived keys must be independently
rederived after this extraction.

The v2 public statement supplies the first239 original input words and the exact
canonical right-frontier CVs/range descriptors once per bounded root. Raw whole
input words are omitted from this parent statement. Every root covers an
independently admitted contiguous range of1..4 actual global window indices.
Initial/terminal whole-job equations remain enabled only at genuine edge ranges;
full-u64 clock/register/program equations are the identical original kernels.

`block_v5_tail_linked_public_windows_preparation_v2.prepare` first emits the
actual original native recursive verifiers. Its binding then calls the qualified
original B5PD chain column producer for EACH selected window and joins those
columns into that SAME parent. Frame12 reads only prefix/frontier public cells;
all other B5PD frames/order/state transitions remain exact. Its final digest is
paired with the original native public B5PD coordinate by the shared compensation
graph. The input-frame hash witness has no full input buffer, tail compression
DAG, or full input private-word inventory. `Stage.ForBackend.publish` uses the
actual producer and independently reconstructing fresh receiver. The selected
source exposes exact original cells, full-u64 window spans, compensation terms,
input root/length/prefix/frontier coordinates for higher byte equations.

`block_v5_input_tail_ancestor_preparation_v1.prepare` verifies ONE real carrier
capture and at most THREE real v2 window-root captures, respecting total fan-in4.
It derives the complete local equality graph from canonical layouts, then lowers
it through the existing admitted graph kernel into the SAME parent rows. Every
root/length/prefix/frontier equality uses the actual authenticated child byte
coordinates, including repeated consumer uses of a provider coordinate. The
standalone ancestor receiver reconstructs the original independently supplied
carrier and window policy; it does not rely on sibling host acceptance. An actual
ancestor publisher and receiver are retained by the new body gate.

This ancestor is explicitly LOCAL and OPEN. It covers an independently pinned
contiguous window interval (up to12 windows). It does not solve carrier placement,
exact global consumer multiplicity or propagation through an arbitrarily large
forest. Repeating it over a large job would reverify the carrier; that is NOT the
claimed once-per-job optimization. The next higher protocol must propagate exact
frontier/prefix requests through bounded summary nodes, place the carrier exactly
once at their independently determined common ancestor, and prove complete range
coverage/adjacency and request multiplicities. Neither the old H grammar nor its
<2^30 clock ingress has been widened or accepted here. Source/global closure,
provider census and canonical CPU driver selection remain OPEN.

The old original public-export route still hashes its large raw-input frame in
recursive replay. The new route must actually be selected instead; attaching a
carrier above that old route does not eliminate its work. Native capacity buses
already export B5PD digests rather than raw input. `Fields.init/validate`, native
public-digest validation and expected-owner policy still perform host digest
reconstruction; this source batch makes NO claim to have cached/eliminated those
host passes. There are no device, proof, benchmark or end-to-end speed results.

The candidate root retains real default/v2/ancestor producer, receiver and row
assembly bodies by address only. Pure fixtures exercise exact source descriptors,
all byte faults, graph allocation rollback, large-input bounded grammar and the
existing original full-u64 compensation oracle. No fixture synthesizes successful
cryptographic admission or invokes proving.
