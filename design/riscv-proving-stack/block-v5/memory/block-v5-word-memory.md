# Packed word memory under B5SS

The opt-in packed memory family commits 36 main columns, compared with 83 in the unchanged v2 encoding and 66 in the v5 compact byte encoding. Addresses remain byte addresses. Each u32 address/value uses two 16-bit limbs; each u64 clock and sorted ordinal uses four. Strict ordering uses bounded radix-65536 gap/carry equations. No clock is narrowed to a field element.

`block_v5_word_memory_artifact_v1` runs roots-only first-round commitments, then replays one independently sized instance at a time, checking roots and exact range counter digests before proving. It retains small per-instance metadata and 256 KiB multiplicity counters per range shard. The independently planned range16 family has a fixed 65,536-value table; each shard stays below the M31 request-count bound. The exact request counts, geometry, instance boundaries, predecessor, roots, relation ABI and shard plan are hashed into `memory_plan_digest` before B5SS challenges.

The sorted quotient constrains transition, ordinal/predecessor link, initial value, final memory and final register projections to the same 36 columns. It also proves every non-Boolean integer limb through range16. `block_v5_word_memory_receiver_v1` freshly verifies every sorted instance and every table shard and closes the link, initial, final memory and optional global register relations before returning an explicitly scoped open transition receipt. It never accepts caller-supplied verified receipts as authority.

Public initial and endpoint files retain the established full sparse image semantics, including input words and untouched nonzero words. Their SHA/length pins, classification and exact ordered first-touch roster remain independent policy. The current implementation reuses canonical byte-source file validation and computes the selected packed sums in a second bounded scan; it is a public CPU custody route, not a succinct source/root proof.

Native-v3 removes old scheduled register/input/output memory compensation. Its register arrays are transcript-bound metadata until sorted global register endpoints close. `block_v5_register_endpoints_v1` pins the policy version, initial/final 32 words, exact final u64 clocks and first-touch mask into `register_endpoint_plan_digest`. Untouched register words must stay unchanged with clock zero. The complete policy requires this digest; old scoped fixtures may omit it. Intermediate native-v3 spans assert PC/clock only, avoiding unproved intermediate register snapshots.

On 2026-09-26 the focused ReleaseFast q8/PoW0 fixture passed: two memory instances at logs 8 and 9; five events; a repeated key across the instance boundary; 95 range16 requests; register clock and private/input clocks with bit 48 set; preserved untouched sparse memory; and fresh range16, source, RW and register closure. Re-pinning/re-sealing a wrong register clock bit 32 and regenerating every proof failed at the global endpoint relation after fresh proofs and table checks. Wrong independent register-mask metadata rejected before a proof was loaded. Local byte-to-word projection parity and out-of-range limb rejection also passed.

The existing v2 q70/PoW26 sorted request/table regression passed 3/3 afterward, including roots-only/retained root and counter parity. These tests qualify the scoped memory family. They do not establish a complete v5 block, opcode/external-to-packed transition closure, global native lookup providers, or an exact recursive forest.

The 36-column main trace saves 47 M31 cells per row versus v2, or 30 versus compact66. This is a trace width result. No whole-prover peak memory or throughput improvement is claimed from the small fixture.

The subsequent packed execution gate passed 8/8 in ReleaseFast with strict testing-allocator teardown: a genuine lightweight native-v3 ADDI segment and a separate family11 SHA/Keccak arithmetic proof with 103 caller accesses. `ForPackedBackend` sidecars use the same nine transition interaction columns as the byte bus, but their quotient linearly combines adjacent authenticated byte cells into packed limbs. New local proof channels replay the frozen universal47 draws and the typed word-memory suffix before mixing local proof claims.

It retains small per-execution byte claim/census entries. Finish checks all execution and sparse caller hooks, exact event count and packed transition closure. The first native register array must match the independently pinned initial register source, and the last must match the pinned final register endpoint array. The exact admitted byte bound is fourteen requests per independently pinned access; descriptor capacity is checked separately. The explicit empty-ordinary protocol in `block_v5_empty_opcode_memory_v1` reconstructs a versioned deterministic family3 entry from the independently pinned zero-slot native shape, frame and execution roots. Its receiver checks that exact entry against a fresh native receipt, consumes no ordinary sidecar proof, and accepts no caller-provided scalar. The actual SHA/Keccak-only fixture contains 103 caller accesses and zero ordinary accesses. Its sorted36 and range16 proofs now generate successfully, but the fixture stops at the zero-component native proof with `InvalidCompositionLogSplit`. Empty-native framing and the remaining fresh caller/global/recursive closures must qualify before this path can issue complete authority. The source-level empty-entry and hook negatives are not yet evidence of a successful end-to-end empty leaf.

That 103-access fixture exposed a packed interaction generator bug: an untyped comptime chunk limit made Zig infer `u11` for `@min(1024, size - begin)`. At log8, `256 * 33` wrapped to 256 in ReleaseFast, so only the first 256 of 8,448 rational terms were inverted. The first missing inverse was row7 term25, the second after-value limb; its range interaction constraint failed although all direct sorted constraints passed. The generator now types both chunk limit and count as `usize` and uses checked multiplication for the inverse span. Field operations, AIR constraints and transcripts are unchanged. The old v2 generator already used a typed `usize` chunk size and was not modified. Core scalar/packed inversion and mixed-weight parity checks passed without a field-kernel change.

The independent regression `block_v5_word_memory_dense_test_root.zig` passed 1/1 in ReleaseFast with `-lc -mcpu=native` and clean testing-allocator teardown. It generated and freshly verified a log8 sorted36 proof and a range16 provider for 103 distinct RW keys, nonzero two-limb after-values and exact clocks with bit 48 set. The receiver closed 103 first touches, 103 final RW endpoints and 2,152 range queries, and matched the independently pinned final sparse root. Changing that root pin rejected with `UntrustedV5EndpointPlan` before either staged proof was consumed. This fixture crosses the missing inverse at index 256 and exercises the complete 8,448-term span without invoking the unrelated empty-native path. Its execution/ROM roster entries are explicit scoped placeholders; its transition claim remains open. It establishes the memory-generator correction and fresh memory/source closure, not execution or complete-block authority.
