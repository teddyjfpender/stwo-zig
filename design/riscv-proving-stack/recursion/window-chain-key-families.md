# From declared window roots to a complete block root

The current shared-original recursive receiver proves and independently checks
one declared **nonterminal** window. It is not yet a self-contained universal
child theorem for another reduction layer. In particular, the receiver performs
execution/global relation closure in host code after verifying the recursive
STARK. A parent which verifies only that STARK does not automatically repeat
those closure equalities.

## Exact current authority boundary

`block_v7_union_receiver_v1.verifyStatement` independently reconstructs the
source admission, compiler capsule, complete fixed roster, expected key, and
public operands; verifies the recursive equation proof; then invokes
`block_v7_window_union_public_closure_v1.close`. This is a sound detached
receiver for its declared scope. The `root.proof` bytes alone are insufficient
to prove a complete block or to nominate their own key.

The leaf key includes a statement-specific `profile.seal` in the fixed-roster
context, plus a statement-specific roster digest in the parent protocol. No
upper layer may replace these with an unverified digest supplied by the child.
A registry is useful only when the verifier independently derives its entries
or when the recursive circuit proves the registry's admission rules.

## Delivered independent building blocks

- `recursion/block_v8_window_chain_v1.zig`: pure exact span adjacency and an
  ordered key/public-input registry. Complete snapshot identities bind PC, all
  registers, and sorted memory. Gaps, overlaps, reorderings, altered keys,
  altered public inputs and fake padded indices are rejected. Merkle padding
  never creates dummy proof jobs. This is metadata, not proof authentication.
- `recursion/block_v8_fresh_boundary_v1.zig`: opaque initial-boundary policy
  derives the state from pinned ELF and input using canonical session
  initialization, executing zero instructions. It rejects a nonzero skipped
  prefix or an arbitrary retained incoming state.
- `recursion/air/block_v8_window_closure_algebra_v1.zig`: graph-capable memory
  provider closure and native register/PC closure arithmetic. These expressions
  must consume the same authenticated physical claim and statement ports as
  the verifier; expected state delta is independently derived or supplied by a
  proved provider, never a free witness. Product integration is pending.
- `block_v8_union_geometry_parity_test_root.zig`: an experiment using two real
  native-tail executions with different input bytes and complete snapshot /
  policy / profile identities. It compares every cold fixed row, namespace,
  routed public schedule and context after removing only the child-profile ID.
  This is the gate before changing key authority; it is not itself a key-family
  qualification.

`publication_qualified` remains false. No product route selects this new layer.

## Geometry-key family feasibility

Much statement data is already symbolic. Union composition inputs include every
physical claim, native base-clock bytes, RAM endpoint and halt constants; the
transcript grammar routes the complete statement frame as public words, roots,
integers and felts. The shared fixed-source compiler deliberately skips
hardcoding initial commitment roots: the public schedule supplies them.

The remaining distinction must be established by full-row parity, not by merely
changing two IDs. A geometry family must bind:

1. Every native opcode family, component width, row log, local-zero custody
   mode and bounded projection layout; every caller kind and relation schema.
2. Lookup dense/sparse choices and provider geometries, memory component count
   and row logs, mask/lifting logs, composition split, FRI geometry and security.
3. Exact transcript operation grammar, public operand schema, path/port
   schedules, arithmetic DAG identities and namespace routing.
4. Protocol domain/version and whether the statement is fresh, nonterminal
   continuation or terminal continuation.

After qualification, the geometry key may replace the *setup* use of
`profile.seal`; per-request profile, epoch, policy and public operands must
remain transcript-bound values. The expected registry must bind the exact
geometry key and exact public-input identity for each ordinal. Removing the
roster digest from key identity is safe only when its equivalent admission is
proved or independently reconstructed outside the child envelope.

Relevant implementations are `block_v7_union_fixed_roster_v1.finish`,
`block_v7_union_parent_protocol_v1`, `air/block_v7_union_composition_v1`,
`air/block_v7_union_transcript_v1`,
`air/block_v5_recursive_parent_fixed_sources_v1.compileUnion`, and
`block_v7_union_public_v1`. No changes to those product modules are included in
this experimental layer.

## Closure equations which the reduction must prove

The six memory equalities are: RAM link sum zero; initialization requests plus
interval provider sum zero; RAM range requests plus range provider sum zero;
first-touch count equal to the interval census; range count equal to its census;
and the sum of both RAM state-delta planes equal to the independently expected
snapshot delta. Transition sum remains open until the actual native and caller
sources close it. Count bounds and canonicality require the independently
admitted finite geometry and authenticated count planes, not field equality
alone.

For every native window, the reduction must derive ordinary memory, clock,
register-state, register-memory and six table partitions from authenticated
physical projection claims. It must derive public register and PC/clock
boundary fractions from the exact statement byte/word ports, rather than
accepting precomputed residuals. Native ordinary-memory and clock relations
close per source; native and caller state/register residuals close per window.
ROM/program fetch counts, all six lookup providers, source transition sums and
exact event counts must close across the admitted complete roster.

The new algebra module supplies the six memory equations and symbolic native
boundary extraction. Wiring their ports and adding program/caller/global
closure to a new explicit protocol remain required before an upper recursive
proof can omit host closure.

## Initial and terminal requirements

Current `block_v7_real_window_policy_v2` requires both incoming and outgoing
halt words to be zero. A chain of these leaves can therefore never prove guest
completion. A new **terminal continuation** must independently admit an
incoming snapshot while proving the real final halt flag and exact output
addresses/length/data under the same ELF/profile. It must not interpret an
arbitrary retained outgoing snapshot as successful completion.

The first span must begin at zero and match the canonical ELF+input initial
state. Intermediate spans must have exact cycle adjacency and full state
identity equality. The final leaf must prove terminal output. Only then may a
root's public statement omit intermediate snapshots while retaining complete
execution and output authority.

## Faster block-scale direction

A frozen expected registry gives an immediate sound development boundary, but
its independent setup is still linear in the number of distinct window
statements. It does not by itself remove snapshot policy work or create a
universal verifier. Reusable geometry-key families amortize DAG compilation,
fixed-row construction, commitment and module plans across many leaves.

For the larger architectural gain, prefer open local-memory endpoint leaves
under one authenticated block epoch and one globally linked endpoint provider,
rather than repeatedly sealing complete intermediate RAM snapshots. The wide
execution and caller witnesses must be constructed and committed once. A
block-wide challenge barrier must bind all relevant first commitments before
LogUp challenges; independent per-window challenges cannot simply be added
later. Bounded coefficient custody or authenticated staged storage is needed
across that barrier. Recursion then authenticates the compact exports and
closes every provider once. This is a separate explicit protocol, not a silent
reinterpretation of existing V7 artifacts.

## Native-only in-proof closure vertical slice (implementation under qualification)

New V8 sibling modules reuse V7 original-verifier compilation and preparation;
they do not change V7 proof bytes or reinterpret its keys. The native-only V8
closure graph reads original physical projection, access, RAM and provider
claims from the existing public operand vector. It computes PC/register
boundary fractions from receiver-derived byte ports; expected state delta from
address/before/after byte triples and canonical epoch challenges; and the six
memory, per-native state/register/memory/clock, program/transition/table/count
and CPU-adjacency equalities. It receives no precomputed closure residual.

`block_v8_union_closed_roster_v1` independently derives closure fixed rows using
`block_v5_recursive_fixed_graph_attach_v1`, reconstructs a separate namespace
for those rows, and combines them with rebased original-verifier fixed rows.
The live path emits real closure MAIN columns through the corresponding
`block_v5_heterogeneous_scoped_graph_rows_v1` implementation, independently
validates both namespaces, drains them into one parent, and compares every
combined fixed row against the cold roster.

`block_v8_union_closed_pipeline_v1` proves that single combined parent using
`block_v8_union_closed_parent_protocol_v1`'s distinct domains. Its fresh receiver
compiles closure shape without evaluating closure success, reconstructs its
own key and exact public operands, and verifies the proof. It does not call the
host-only `Closure.close` as an acceptance substitute. The original proof and
its capture are unnecessary after production. Callers are explicitly rejected
in this first slice; terminal continuation remains unimplemented.

This step still independently reconstructs source admission from metadata.
Original V7 transcript frames contain source identity hashes, not every raw
CPU/snapshot field, so the V8 public bus explicitly includes receiver-derived
metadata byte ports and epoch draws. They are absorbed in its public-input
identity. An upper reduction must authenticate that exact identity from an
independently admitted registry or prove equivalent metadata admission. This
is not yet a universal child which may nominate arbitrary metadata under a
geometry-only key.

The focused gate `block_v8_union_closed_test_root.zig` uses two genuine native
RAM segments, tests compensated +1/-1 per-window state claims (aggregate
preserved), and produces a recursive proof followed by fresh receiving after
the original and capture are destroyed. Qualification results belong in the
actual test log; the presence of these modules alone is not a passed gate.

### Qualified native-only evidence, 29 October

The focused native-only combined proof passes both diagnostic q8/PoW0 and
canonical q70/PoW26 source-and-parent gates. The canonical tiny gate reconstructs
metadata from durable bytes and independently pinned ELF/snapshots, destroys
the original proof and capture, then derives the V8 key afresh and verifies.
Its root is 928,590 bytes. These gate runtimes are not benchmark medians.

A genuine 4,194,304-instruction canonical saved original now also yields a fresh
V8 root with closure inside the proof. It has four native segments, four RAM
components and 257,927 changed snapshot words. Root SHA-256:
`f6d1327d91804ae0e247d145fc85515b405829b04b57c9a8f9794d233f2703cd`.

This is one isolated CPU/eight-worker observation. It **excludes original source

theorem needs global RAM consistency and final HALT/output, not these full
intermediate/final snapshot boundaries; this is not its production requirement.

The measurement exposed repeated whole-vector validation inside each public
wire accessor, despite admission already validating the vector before its wire
walk. Removing that quadratic repeated scan is under qualification while
retaining complete admission and per-access bounds. No speedup is recorded
until a new isolated observation completes.
