# Independent streamed-bottom/dense-upper source review

Reviewed source authority: `0825ec08b410747654623f7a31fdf57a4a2b7254`. This is a read-only review, not an independent rerun of its tests or full-block performance qualification.

No concrete arithmetic, custody, default-compatibility or admission blocker was found within the changed code.

The core validates opaque source variable counts in1..30 before building its dense upper array. The placeholder bottom owns no planes. `buildSourceDense` computes the same first adjacent reduction through the existing source authority, then retains the original `nextLayer` results at every higher level. Output popping remains ordinary; only the actual bottom is intercepted by the opaque source oracle. Checkpoint2 still uses the existing sparse builder and lazy missing-level logic. The added compile-time checkpoint guard avoids indexing the empty presence array in dense-upper mode. Source callbacks still join before their immutable contexts retire.

Dense construction failure cleans only initialized layers and frees the descriptor array. Successful layers move into the existing stack and oracle owners exactly once. The bottom placeholder is never interpreted as a real empty MLE; its retirement owns no backing. The minimal allowed one-variable case builds its root at index1 and uses the raw source constant mask at the bottom. `variables==0` is rejected before this array access.

Operationally, bottom streaming and upper checkpoint storage are intentionally independent. Unset streaming still takes the original materialized default136 or tight104 paths. Checkpoint2 plus streaming retains its68N route. Streaming with dense upper storage selects the source API and80N admission, and terminal binding replays narrow metadata rather than referencing absent raw planes. The same frozen policy reaches coordinator retention and child admission; no new producer-selected security profile or proof format is introduced.

The80N derivation conservatively retains all original upper backing capacities: less than64N across each geometric bank. At common outer height h>=1, Eq construction contributes at most6Nmax and a single joined resize-copy fallback at most8Nmax; these fit below78N even without credit for retired bank layers. At the raw-bottom phase, all upper oracles have retired, and32N secure first-fold outputs plus12Nmax Eq and16Nmax fallback remain below60N. The80N reserve adds the unchanged checked metadata and takes a separate maximum with binding/projection scratch. Public explicit source cloning is outside this production path. This is a live requested/original-capacity allowance, not an RSS, recycler-cache, stack or total-device-memory bound.

The source commit's Safe/Fast tests cover old proof/artifact/next-draw equivalence for Q and OM, mixed and minimal sizes, held leases, terminal verification, callback failures, malformed source counts, all allocation failures, exact admission caps, retained original capacities and nonresizable fallback owners. Those are existing qualification records, not tests independently rerun by this reviewer. The parent must still retain actual complete-run artifact parity and fresh-receiver evidence for any operational default promotion. Source streaming is a memory/work tradeoff; its earlier sparse variant's full-block CPU regression must not be hidden by the smaller memory number.
