# Experimental retained CPU evaluation storage

This opt-in policy preserves commitments, transcript and every proof byte. It
is disabled by default. The first same-binary quiet ABBA on four real Ethereum
packets measured compact22.79/24.80s versus mapped26.83/27.86s: retaining every
CPU evaluation on disk is slower on this host. The receipt records RSS and
Darwin footprint separately; neither may be substituted for the other.

CPU native2n commitment and constraint domains match. Fixed keys remain leased
compact trees, and separately sized4n crypto truths keep compact native
coefficients. CPU mutable trees retain mapped LDE values using the existing PCS
allocator hook and .never coefficient policy. Allocation is bounded globally,
rounds actual mappings to pages, and frees through the recorded tree allocator.
Stage-one MAIN writeback completes before DONTNEED. The store outlives all
workers and both successful and failed PCS teardown. The current hook relocates
already extended data, with an additional intermediate detach for arena-backed
batches; it is not a direct mapped FFT destination.

The shared bounded-coset evaluator accepts exact canonical-domain values as
immutable contiguous slices. Part p uses [p*n,(p+1)*n); predecessor values use
part p xor1 and the existing core predecessor index. Only coefficient sources
allocate scratch and undergo FFTs. Mixed source groups preserve paired-buffer
reuse, unmarked addresses and arbitrary part order. A committed2n domain cannot
substitute for disjoint4n evaluations. OODS/constraint equations are unchanged.

Safe/Fast tests cover every mixture of four coefficient/retained sources on2n
and4n, previous-row masks, arbitrary/repeated part orders, exact borrowed
addresses, all allocation failures, actual serial/two-lane five-proof parity,
and partial mapped-budget failure. Foreign allocators reject by vtable before
reading their potentially undefined context. A four-packet/seven-proof durable
run and separate fresh receiver preserve all proofs, manifest, RAM and cost
against compact control.

The measurement explains the regression: summed worker composition8.22→4.44s,
trace decommit2.92→0.39s and FRI6.20→4.10s improve, but MAIN commit5.42→12.31s,
INTER commit4.17→10.44s and sampling0.94→1.99s grow. These are worker intervals,
not wall-time components. The next experiment should retain hot interactions
without file relocation, or reconstruct/cache bounded MAIN expansions after the
manifest barrier, rather than write every LDE to disk. Any promotion requires
whole-pipeline measurement, proof parity, fresh verification and peak-memory
accounting. No GPU or recursive acceptance is established by this experiment.
