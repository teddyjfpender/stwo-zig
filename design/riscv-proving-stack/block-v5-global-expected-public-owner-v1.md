# Durable expected public owner and new root normalization v1

This source candidate adds a real durable public-job owner, the original new export-root publisher/fresh receiver, and a separate large-input normalizer for that exact root protocol. It grants no complete-block or source-proof authority and selects no canonical default. Its author has run formatting and source review only; no compiler, fixture, proof, guest, segment or device execution is claimed.

`block_v5_global_expected_public_job_v1.Expected` carries independently expected coverage/seal/recipe, one immutable input vector, original public data for every window, exact profile/full-u64 endpoints and the independent RegisterWindows plan. `validate` checks the original public data/decoder/window rules. `requireEqual` compares all original scalar/root/completion/output fields and input words, not just a file SHA or B5PD digest. `bind` additionally checks every genuine independently restored capacity admission, complete original coverage, sealed identity, profile and endpoints. It returns the original typed public policy with the retained register plan; it does not construct a receipt or admit a transported key.

The durable `B5EP/public/v1` JSON has one `input_words` member. Per-window records contain original PCs/clock, register state/clocks, roots, completion, output fields, profile and full-u64 endpoints. Register windows are reconstructed from these original fields rather than serialized again as a second window-state copy. Count-first serialization precedes the exact-byte allocation. Explicit file, parsed heap, window, input and aggregate output limits apply. Shared caller allocators still impose their outer aggregate cap. The nested owner retains an actual shared parent allocator through final teardown; no whole-process RSS enforcement is claimed.

`block_v5_global_expected_public_file_v1.read/decode` requires both a storage length/hash pin and **all independently expected public job fields**. Hashes validate transport only. Parsed arrays own their lifetime, and the input is allocated once. References are explicitly retained and released across sessions/artifacts; this is a runtime ownership contract rather than language-enforced move-only storage. No reader may manufacture original capacity/caller/provider admissions from this file: existing independent admission owners/loaders remain required.

## Large input and precise higher-parent cells

The original capacity child bus exports its **B5PD digest**, seven roots, row counts and native compensation/open claims. Original capacity/caller fused statements export slots, commitments and claims; they do **not** serialize the block `PublicData.input_words`. Their existing generic 1M-cell per-child bound therefore does not scale with block input. This batch does not widen that bound or invent a legacy child migration.

The **new export root** includes the full input once in `Bus.Values.mixData`. `block_v5_global_public_export_normalizer_v1.normalize` captures the actual new `Protocol.Admission.mix` directly under an explicit default **64M-cell** bound. It never routes that root through legacy heterogeneous/open-child normalization. Descriptors clone temporary headers/felts and borrow the single input; there is no full input-sized `[4]M31` cell array. `cell` uses binary search for the last frame start at or before the coordinate, handling duplicate starts from empty calls, then performs exact typed extent decoding. Lookup cost is logarithmic in frame count.

The normalizer exposes:

- `window(index)`: exact `{frame,first_cell,word_count}` for PCs/clock, initial/final registers, last clocks, completion, decoded words and four global-cycle words.
- `WindowLayout.firstCycle/lastCycle`: two little-endian u32 cells per full-u64 endpoint. Every cell is four original bytes; no full word/cycle is reduced to M31.
- `exportTerms(index)`: the three actual original `Admission.exportCells` descriptors for native compensation, register compensation and terminal ROM boundary, in their one genuine felt frame.
- `originalCell(child, coordinate)` and `originalFrame(child, ordinal)`: exact offsets from an independently admitted original child's public statement into the actual new root statement. Original semantic claim coordinates can therefore be requested as original lower-proof bytes.
- `frameAt`, `cell`, and `replay`: the actual original operation and routed bytes under new public circuit 4_300_200.

`validate` independently replays the original admission, checks exact word/root/integer/felt contents and positions, derives every source from original owned invocation spans, and rederives every term descriptor. An altered offset cannot reuse an independently valid public-input digest. `sourceAuthority` names the new normalizer/owner/receiver recipe for an explicitly admitted higher-parent adapter; the hash itself is no proof or completeness authority.

The original-child locator observes the exact immutable first owned words span when `child.mix` invokes the real root serializer, before descriptor cloning. It does not search for an equal value or root, and an unrelated span with identical words cannot become a source. Validation rederives each start from that same invocation and compares every contiguous original frame, its type, contents and relative cell position. This additive normalizer requires no change to the frozen heterogeneous child serializer. Unsupported missing or repeated anchors fail closed.

The large-input source fixture exercises the **actual new `Bus.Values.mix` serializer** with more than 1M input words, one borrowed input and less than 64KiB descriptor metadata, compares native and normalized channel bytes, and explicitly confirms its incomplete literal proposal is not valid policy. It never synthesizes positive cryptographic admission. Genuine producer/fresh receiver/normalizer bodies are retained separately for root compiler qualification.
