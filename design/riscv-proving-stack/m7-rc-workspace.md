# M7 proof-scoped resident composition workspace

Status: source reviewed; pure allocation/lifetime controls passed 10/10 and physical snapshot controls passed 7/7 (six imported controls overlap). The complete legacy Ethereum driver also passes semantic no-output compilation (23.52 s), which checks the production adapter and its module dependencies. Production numerical parity, stream ordering and performance remain unqualified.

`STWO_RV64_RC_ROLE_WORKSPACE=1` requests one maximum-sized arena for the outer composition callback. It is never retained across proofs or classes. The native composition contexts remain unchanged. Role metadata, inverse planes, quotient buckets and final composition coefficients have independent allocation owners. The arena retires before final composition output/commitment allocation.

The exact legacy device model computes the maximum arena held alongside every accumulated metadata/bucket allocation. This can exceed the original per-role peak: the regression fixture exposes a 32 MiB higher peak, which the physical guard must refuse when unavailable. A read-only snapshot covers live allocations in every context sharing that physical arena, including small-slab occupancy and maximum virtual free range. Unavailable/malformed snapshot ABI and insufficient capacity fail closed. This is an allocation preflight within the current configured arena, not a reservation, a placement/progress guarantee, or a global admission enablement. Concurrent mutations or external allocations can still make the actual allocator refuse. No arena size increases or unaudited host-envelope claims are introduced; the host model remains unknown and cannot enable global admission or new GKR formats.

With `STWO_RV64_COMPOSITION_ENQUEUE=0`, every role still joins both lanes before the shared arena can be overwritten by the next role. With enqueue enabled, ingress and numerical readers share lane zero. Error cleanup joins before releasing the workspace. Final buckets/coefficients remain outside the arena. Both execution modes require a production proof gate before promotion.

A subsequent source audit caught that outer and native composition share a Context. The first Context-wide capability was never runtime tested; its obsolete compilation was stopped. The corrected capability is carried only in the outer Job, with generic/native entry points defaulting false. The opt-in environment alone cannot activate this path for native composition.
