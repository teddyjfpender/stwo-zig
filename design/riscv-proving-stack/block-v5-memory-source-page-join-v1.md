# Fresh PAGE and strict RAM source join

This isolated receiver consumes real raw/fold PAGE, two-event lane and range16
proofs through their original fresh CPU verifiers. It authenticates the source
streams and sorted-memory initial/final joins under independently admitted
source pins. It returns an open transition result; canonical driver, transport,
MemoryJoin and recursive aggregation are not switched by this batch.

Both PAGE kind rosters are complete, independent, ordered and consumed once.
Each kind is verified through a consuming roster batch. The full original
SOURCE/Word epoch is reconstructed on batch entry and exit; each selected pin,
proof, descriptor inventory, fixed root, transcript and AIR is still verified
independently. The single-page API retains its full epoch check. No caller can
select an unchecked verification mode or supply a reusable epoch receipt.
During successful source verification this reduces full-roster reconstructions
from one plus the total page count to five, including the join's own entry
check. This is a work-count reduction, not a measured proving speedup. Callback
accumulations are provisional until both batches and all subsequent joins
succeed, and the owner requires exclusive access throughout verification.
The actual PAGE verifier rebuilds the original semantic graph, fixed roots,
descriptor inventory, masks and local claim closures. Fold descriptors are
bounded by independently pinned page count and validated against inventory and
fixed roots. A digest, claimed scalar, host file check, or callback-provided
VerifiedPage proposal cannot enter this owner in place of original proof bytes.

## Actual API and ownership

`block_v5_memory_source_page_join_owner_v1.Owner.create(backing, *Context,
LaneReceiver.Pins, Limits)` owns copied PAGE rosters and lane/range/seal metadata,
plus one immutable setup for original SHA, BLAKE and arithmetic equations. Its
stable arena and setup admission scratch share the setup budget. Original
source structs contain independently supplied scalar pins, not proof receipts.

`Owner.verify(backing, Loader)` is consuming on every path after entry. Loader
callbacks allocate decoded original proofs and public fold descriptors from
the supplied bounded live allocator. At most one original proof/page is live;
there is one compact range-sum scalar per independently admitted RAM instance.
Every failure consumes/releases the original proof through its verifier,
releases current descriptors and temporary plans, and leaves the owner safe
to deinitialize. Failed sessions cannot replay partially taken proofs. The
owner is coordinated by one caller; concurrent verify/deinit is unsupported.

The result reports actual event/endpoint/range/page counts, roots, base seal,
PAGE epoch and source/memory identities alongside the open transition sum.
The empty-RAM route loads no lane/range proof; five source SHA streams and the
actual fold empty/root proof obligations still remain, even for empty files.
Writable input behavior is preserved: initial input words may have different
proved final values at their touched endpoints.

## Remaining complete-block links

The CPU result must be consumed by the original fresh native/caller packed
access transition equation with exact all-RW event census and actual access
witness roots. Other original global program/register/state/lookup/byte and
accounting closures remain mandatory and independently scoped. A source
context/epoch identity does not substitute any of them.

For self-contained recursive block authority, actual PAGE, lane and range
verifier equations and these aggregate joins must be attached to the genuine
final parent, with authenticated original claim-byte inputs. The independently
expected source layout/initial-image/touch/final/public input pins must connect
to the real public/job source protocol. The wide original input carrier and
its exact consumers must prove the original B5PD input link under their new
grammar; neither host matching hashes nor B5WMv1's unproved input-link flag
discharges it. This batch cannot mint a ClosedBlock receipt.
