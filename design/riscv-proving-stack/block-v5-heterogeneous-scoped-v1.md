`Cohorts.init` puts each real native arithmetic/fused and caller arithmetic/fused companion group together first, then combines each independently derived field-safe six-table provider group, and finally adds the remaining exact RAM/range/ROM roster. Quartets carry incomplete tails; there is no power-of-two rounding. Native PC/clock spans derive only from actual native contributors. Provider-only cohorts have no span.

`Routes.init` assigns a zero scope to the actual lowest common ancestor of all its independently selected participants. The validator reconstructs this routing rather than accepting a mutation checksum. Missing terms, duplicate physical uses, cycles, altered selectors/signs, reordered keys and resource-cap violations reject. Keys keep execution/window, provider group and table kind distinct; byte requests occur once in their original group and once in their separate known-accounting coordinate.

The first local parents freshly verify the actual original typed leaf bytes. Their export AIR reads original public byte cells through exact public-wire requests and constrains the QM31 summary. Higher parents freshly verify the actual lower compact parent bytes and constrain each outgoing summary to the exact sum of lower authenticated export cells. The public statement contains only the current compact outputs, independent lower key/public/source identities and optional true native span. It never mixes lower `Source.mix` or replays original descendant frames.

`Preparation.prepareVerifierRows` uses original `State.plan`, arithmetic/hash/transcript verifier kernels, injective namespaces and shared parent arithmetic cohorts. `Equations.prepare` is attached to those same actual rows and public-supply schedule. `Stage.ForBackend(Cpu).publish` derives and checks the independently selected setup geometry and exact wire schedule, invokes the real original reusable parent producer, encodes the original parent STARK grammar under the distinct B5Z protocol, freshly verifies the parent, and only then calls its sink. ## Honest costs and hard bounds

With `n` leaves, `t` original contributions and depth `h`, exact descendant-ID topology costs O(nh) integers. Local claim bytes are read once at original leaf/local parents. A scope is forwarded only until its complete LCA; open scopes can still require O(t h) exports in the worst case. The whole source-cell cap bounds every independent node policy. No ancestor transcript repeats full original descendant public frames, removing the first hierarchy's O(n h^2) policy-cell copying pattern. This is an architecture statement, not a measured runtime or RAM improvement.

Full policy normalization and semantic re-derivation currently repeat at node admission. Their worst-case host-validation work can remain quadratic in the roster; an independently pinned immutable admission/catalog handoff is a separate needed improvement. These checks are retained instead of silently trusting a re-sealed recipe. The graph lowerer also currently specializes the original lowering plumbing in a new module while reusing the same unchanged actual arithmetic kernels.

Defaults: semantic children <=1,024 / exports <=65,536; requirements <=131,072; original contribution terms <=1,048,576; semantic and requirement owners each <=256 MiB; cohort nodes <=32,768 / descendant IDs <=1,048,576 / owner <=64 MiB; route slot IDs <=4,194,304 / owner <=128 MiB; per-node public source cells <=1,048,576; whole node-policy source cells <=67,108,864; graph inputs <=4,194,304. Stage shared live allocations <=4 GiB, child proof bytes <=128 MiB and parent proof bytes <=512 MiB. Actual original row/domain/proof resource checks remain additional authorities. Bounds are real checked allocations/counts, not estimates replacing proof admission.
