# Strict RAM lane recursive verifier, version 1

This source candidate records the genuine canonical two-event RAM verifier. It
is isolated from the canonical driver and complete receiver until its source
and actual-body gates qualify and provider transport/global closure integrate.
The implementing agent ran formatting only: no compiler, tests, commitments,
STARKs, guests, segments, benchmarks or device jobs. It makes no proof or speed
claim.

`Admission.Prepared.init` accepts the independently pinned actual `Lane.Pin`,
B5SS policy/roster and explicit capture/preparation budgets. It admits the real
mode1 sorted-memory entry, physical row log, fixed/main roots, endpoints, exact range
request census and PCS config before allocating the three column-log arrays.
The geometry is fixed 24/main 54/interaction 92, 117 equations, degree4 and four
composition chunks. The reusable template binds the actual row log, equation
sources and security; changing endpoints, roots or public claims does not enter
setup as constants.

`Capture.ForBackend(B).verifyBorrowed` invokes the original CPU/core verifier
through `WordPCS.verifyCaptureBorrowed`, reconstructing all 24 deterministic
fixed columns under a bounded allocator. It uses the actual lane component,
independent two-root pin, original proof channels and complete PCS verifier.
Only owned capture arrays survive this call; the original proof is borrowed
and remains owned by its caller. The capture mutation seal checks consistency
and never supplies proof authority.

The symbolic composition adapter shares the unchanged generic Word/Lane AIR
body through additive `constraintsWithEndpoints` methods. The old methods
forward exactly their previous endpoint conversions. The adapter records all
94 direct and 23 interaction equations in the native order, the actual coset
denominator, Horner accumulation and four-chunk reconstruction. Its masks open
all 54 current main values and exactly the 9 previous lane1 key/clock/after
values. No duplicated AIR, corrected equation index or virtual event log is
used. DEEP uses the actual native component masks. Existing symbolic FRI,
query, Merkle, BLAKE3 and proof-of-work adapters remain mandatory.

Transcript replay preserves B5SS, all 47 universal challenge pairs, the 5 packed
word suffix pairs, the original B5R2 proof tag/ABI, full pin identity, and all 90
claim words: the two event-count words, 84 sum limbs and four endpoint/range
count words. Fixed and main roots are independently supplied because the lane
proof resets its transcript after those commitments; every actual Merkle path
read is linked to those roots. It then replays the original interaction,
composition, DEEP/FRI, PoW and query channel without a new reset.

The distinct public bus circuit is 4_200_007. `Bus.Values.fromLanes` accepts
`(*const Admission.Prepared, Lane.OpenReceipt)` and independently derives all
61 equation inputs: 23 normalized planes, 9 preceding endpoint limbs, 11 first
and 11 last transition limbs, 2 global boundary flags, 3 endpoint fractions and 2
endpoint counts. These and the transcript bytes derive from the same actual
pin, B5SS digest and proposed native claims. All census, u64 clock/ordinal,
u32 address/value and source-policy fields remain bound. A proposed open claim
is only a public statement until the actual recursive proof verifies.

`Stage.ForBackend(B).publish` borrows the real lane proof, freshly captures it,
builds the real verifier rows and proves the distinct reusable parent.
`publishFromVerifiedCapture` validates the complete capture/policy first.
Optional `SetupCache = Cache.ForModules(B, Bus, Protocol)` uses the existing
one-entry bounded cache; the consuming path releases one-shot rows while
retaining routing metadata. Both cold and cached paths encode the parent and
freshly call `Leaf.verify` before `Sink.put_lanes(context,index,*Artifact)`.
Success transfers the artifact; failure keeps ownership in the stage.
`Artifact` exposes bytes/key/keyID/schedule, the actual `Lane.OpenReceipt` in
`native`, and independently checked public values. Capture/preparation caps
bound allocations; borrowed roster/cache/pool policy must remain alive through
publication. Every error path tears down its owned graph, rows, proof and byte
buffers.

`Leaf.verify` takes proof bytes and independent key/keyID/schedule/Prepared
plus proposed native sums. It derives the public values itself, strictly
decodes and freshly verifies the actual parent proof and public wire closure.
Its `OpenEquation` leaves transition/link/initial/endpoint/range cancellation
open. Exact sequence/endpoints, fresh providers and all-family detached/global
closure remain necessary; this adapter does not issue a complete block receipt.

`RAM recursion:`. Seven named fixtures cover arbitrary canonical OODS parity
against the native 117-equation adapter, odd/even and boundary/interior setup
identity, shifted/main/interaction/chunk/public-input mutations, exact lifted
endpoint/mask/degree parity, original 52-pair and 90-word transcript framing,
independent root/endpoint/log/security/census/schedule rejection, raw malformed
field limbs, and exhaustive graph/policy allocation failures. Literal metadata
and arbitrary OODS values never enter a synthetic proof acceptance path. The
separate `block_v5_ram_lanes_recursive_codegen.zig` object root retains actual
capture/preparation/publication/cache/fresh-receive bodies without invoking
any. Root alone may run the commands pinned in
`ram-lanes-recursion-source-candidate-v1.json` under the campaign's
`cpu-performance-gates-v1` directory.

Remaining production work is typed provider-leaf transport and independent
key/schedule policy, recursive global bus cancellation/completeness and
canonical driver orchestration. A per-leaf transport may store index, expected
keyID, actual interaction claim and proof bytes; shared policy retains the
trusted Prepared and template key/schedule. Reloaded sums must be verified by
the actual leaf equations before any global claim is consumed. Empty RAM has
no lane instances and must continue using independently admitted typed absence,
not a fabricated zero lane receipt.
