# OM31 CPU recursion statement

This is a complete physical CPU statement adapter, not an accepting execution root. Its circuit checks the same local LogUp-GKR proof, canonical child receipt, terminal marginals and eta used by the native receiver, the original CPU and provider constraints, and the native OM31 PCS/FRI proof. Native execution-wide inventory, initial input, final output, adjacency and global RAM/KIO/Wire closure remain required at the root.

The graph uses the shared original equation emitters in `gkr_local/constraint_authority.zig`: MAIN residuals first, the three Eq/prefix binding residuals next, and global physical-relation residuals last. Original mask offsets and vanishing-denominator scaling are preserved. Row points use the checked GKR artifact's instance suffix; lane weights and binding targets are derived from that artifact inside the circuit. No producer-supplied terminal marginal or eta becomes a circuit constant.

`cpu_child.zig` checks the original numerical verifier kernel, excludes output denominator poles, closes the entire local sum, hashes the original canonical receipt visitor, and draws eta at the native transcript position. Its byte writer preserves the receipt's 31-byte prefix and ensuing unaligned words. Each dynamic byte is range checked and constrained to its original canonical word.

`cpu_leaf.Statement` frames ordinal, statement digest, FIXED and MAIN roots, manifest digest, the computed receipt, every physical claim, steps, epoch, both PC endpoints, all register endpoints and clocks, sponge ID, and each physical role's counts and first ID. Derived nonempty flags are constrained rather than trusted. All request scalars consumed by an equation are public-frame wires. Immutable program, geometry, profile/configuration and setup authority remain admitted topology. Named candidate profiles must match the exact configuration. This preserves the existing documented security assumptions and does not certify whole-protocol security.

The physical transcript uses the shared worker/fixed framing, mixes FIXED and MAIN, mixes the manifest and every physical claim, then INTER and the original PCS transcript. The shared manifest challenge authority supplies RAM/KIO/Wire challenges.

The root must reconstruct `cpu_leaf.expectedWords` from its independently validated inventory/request/manifest, native-verified receipt and public boundary claims. It must compare those exact words with the root-authenticated leaf frame and authenticate the frame digest as circuit outputs. The opaque CPU statement digest alone is insufficient. Large public boundary cell lists are not hashed in the circuit: the root recomputes their claims using `expected_boundary.zig`. It then closes each global relation independently across the complete roster and validates coverage, adjacency and completion. These obligations are not relaxed by a successful leaf circuit.

Qualification uses an actual service CPU shard produced by the existing coordinator fixture, a fresh native receiver and verified proof capture. The complete graph matches the native final transcript. Mutation cases cover a public PC endpoint and a high OM31 physical-sample coordinate, with further public-claim/root checks in the focused test. Separate child tests check canonical native receipt/eta parity for v1 and v3 and reject a changed child proof or receipt. The generic OODS adapter has an eight-coordinate differential test against the original native component.

The measured tiny-service graph has 3,541,906 variables and 588,240 Blake G gates. These are circuit construction counts, not recursive proof generation timings or production-layout cost estimates. The fixture includes the CPU roster and Keccak bridge; full-production V3 service layouts and root assembly require their own qualification.
