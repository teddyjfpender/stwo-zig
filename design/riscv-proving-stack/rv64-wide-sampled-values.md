# Shared bounded wide sampled-point evaluation

The wide correctness route evaluated retained M31 coefficients separately for every column and sampled point, using scalar OM31 products at each coefficient merge. The existing optimized QM31 route already factors its product basis and batches coefficient work. This change applies that organization to OM31 using the existing typed point-factor authority and packed OM31 secure-by-M31 kernels.

All retained-coefficient targets across trees share groups keyed by the exact coefficient log and exact normalized point coordinates. Normalization remains `point.repeatedDouble(global_log-column.log_size)`: the commitment-column log, not the possibly lower polynomial-coefficient log, determines the fold. Different point-list shapes and duplicate points share the same basis without aliasing their independent outputs. Keys compare complete canonical coordinates, not only a hash.

Each group materializes two balanced subset-product bases of lengths `2^ceil(log/2)` and `2^floor(log/2)`, then evaluates coefficient blocks with packed secure-by-base dots and one secure high-factor product per block. Atlog22 the entire shared basis is128KiB, rather than an N-sized vector. The largest supported circle geometry needs3MiB. A coordinator-only HostBudgetAllocator caps **all group metadata and current basis scratch together** at32MiB per proof. Cap refusal discards the plan and executes the existing bounded scalar fallback; genuine child allocator OOM propagates. Output arrays and the existing single-column interpolation fallback remain on their ordinary proof allocator and are not falsely included in this scratch bound.

Column tasks reuse `row_work.forEachRange`, the existing scoped pool and nonblocking lease/fallback. Every task borrows immutable coefficients/bases and writes distinct output slots; all consumers join before basis destruction or coefficient release. No new pool, global cache, full LDE retention or witness replay is introduced. Evaluation-only input columns still interpolate once per column. The shared scalar evaluator also keeps the first coefficient merge as `factor.mulM31(coefficient)` rather than multiplying a lifted zero-high-half secure value.

Qualification covers cross-tree grouping, exact folded-point distinctions when coefficient and column degrees differ, signed/high-coordinate points, ragged geometry, tiny scratch-cap fallback, unavailable pool leases and all allocation failures. The focused suite passes96tests in Safe and Fast. The actual full OM31 STARK suite passes Safe/Fast, including fresh receiver, tampering, exhaustive owner/OOM tests and fold1/fold4 uniform, mixed and hybrid storage. All six printed durable proof hashes equal the pre-change wide-quotient receipts.

A shared-host micro of16log16 coefficient columns at one point took24.19ms in the scalar typed evaluator and1.86ms including construction of the shared16KiB split basis, about13×. This is a numerical kernel result, not a block or GPU speed claim. The root's independent production recorder identified sampled-value evaluation as25.6s of40.7s native proving in the preceding combined prefix; post-integration prefix measurements remain required.
