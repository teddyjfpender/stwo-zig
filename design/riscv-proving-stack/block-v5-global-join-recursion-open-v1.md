# Open symbolic global join adapter v1

This source candidate records the existing `block_v5_global_join_algebra_v1.Algebra` over symbolic QM31 values and places its generated arithmetic cohorts in the same parent witness as the original heterogeneous child verifiers and their source pairing. It does not produce a closed-block statement. Detached all-family fresh verification remains mandatory. No compiler, proof, segment or device run was performed by the implementing agent.

`air/block_v5_global_join_composition_v1.Plan` supplies independently selected references to original child `.felts` transcript frames. Each reference names a physical child, family kind, index, frame and felt. The recorder reconstructs the four M31 coordinates of each QM31 claim from its sixteen original byte cells; it never treats a receipt, hash or aggregate supplied by a host as verifier authority. The original frame and its byte encoding are checked before recording. The resulting graph retains a `{child, cell, part}` receipt for every input.

The shared algebra supplies separate zero equations for each execution's state sum, each canonical register window, and each provider group/table kind. Lookup request membership is ordered by execution, and a byte partition is attached exactly once to the corresponding request's `range_check_8_8` demand. The transition and program equations remain separate. The final nine-field residual preserves the original subtraction of auxiliary clock memory and adds every byte partition once. No cross-execution, cross-window or cross-group cancellation is accepted in place of those separate equations.

`MappingPin` is an independent coordinate-recipe pin, not a proof-carried authority. Its plan digest includes every reference and sum, custody mode, scope index, request membership, byte-part index and the original algebra/source fingerprint. `block_v5_global_join_parent_preparation_v1.admit` compares it to the independently reconstructed heterogeneous coverage and seal. It also requires exact execution/state/byte counts, provider-group count, register-window count and canonical mode1. This admits supplied metadata; it does not prove that a particular coordinate has the intended semantic role.

The actual integration is `block_v5_global_join_parent_preparation_v1.prepare`. It first builds all original child verifier and pairing rows, then uses `Prepared.attachGraph` to lower the aggregate with the existing shared arithmetic compiler, relocate its namespace, join the actual columns, and append exact public-input multiplicities to the parent's existing supply schedule. The graph, namespace, full mapping, coverage and source identity feed the parent's setup context. Both graph scratch and final rows charge the parent allocator; the graph's local preparation cap is subordinate to the parent cap. Errors tear down the owning preparation.

`block_v5_heterogeneous_recursive_stage_v1.Options.aggregate` selects this real integration during publication; the default remains the open heterogeneous path without aggregate equations. A supplied mapping that fails admission is an error. The artifact's scoped-equation flag only describes equations included in the fresh parent verification. Both modes retain outstanding complete aggregate/source obligations.

Several detached terms are derived from public endpoints rather than exported as scalar claims: public register/state compensation, terminal program boundary decoding, initial/final RAM source values and register endpoint/provider closure. This adapter cannot manufacture their authority or replace their original derivation with free scalar inputs. A complete successor must authenticate the exact semantic coordinate recipe and reproduce those derivations from authenticated endpoint cells and the actual shared challenge context. It must also close RAM link/initial/endpoint/range obligations, counts and subtype/typed-absence coverage. `aggregate_semantic_coverage_pending` and `endpoint_source_authority_pending` remain true; there is no complete-block token or default activation.

The proposed root qualification filter is `global join recursion:`. It covers native-versus-symbolic equality, mixed QM31 byte reconstruction, separately scoped failures, provider kind/group cancellation, byte membership and auxiliary sign, changed source/mapping rejection, exhaustive allocation rollback, actual generated-cohort/source multiplicities and evaluation mutations, and parent census admission. A body marker retains real graph preparation, row attachment and the original stage publication branch without invoking proofs. Source hashes and exact safe commands are recorded in `global-join-recursion-source-candidate-v1.json`.
