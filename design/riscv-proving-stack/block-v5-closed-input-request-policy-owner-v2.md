# Durable version5 closed input-request selection

The new `block_v5_cpu_owned_closed_input_request_forest_v2` facade selects an actual topological version5 producer/reconstruction path. It keeps the original independently reconstructed Snapshot, true capacity-native admissions, immutable whole-job input, exact original carrier policy, WM/v2 protocols, minimum fan-in-four geometry and all original verifier checks. No existing Driver/default, version4 owner/runner or proof grammar is changed.

`Selection` has the original typed `snapshot`, `independently_expected` out-of-band pins, native/carrier file `loader`, independently selected security `profile`, and resource `limits`. `publish` returns `Built{owner,root}` with the actual final fresh capture transferred. `reconstruct` accepts only the exact independent window/node file census and derives every expected key from real freshly verified original children before decoding proposed parent bytes. `Owner.readRoot` subsequently verifies a stored root against these already derived keys while the caller retains its policy owner. File SHA/length pins provide bounded transport admission, never cryptographic authority.

The owner retains the original Snapshot and its exact native/key/schedule/public/coverage custody. Its heap-stable metadata arena and parent-retaining SharedHostBudget own WM policies, file pins and node specs. Each live preparation uses a bounded parent-retaining worker budget and at most four original child captures; the unique carrier is verified only at the independently selected final node. Partial build failures release rows/captures/metadata and remove only files newly published by that invocation. Successful Built teardown destroys the fresh root before its borrowed policy owner. Reconstruct errors never delete input files.

Every node spec is derived topologically from the genuine version5 rows, including real original child verifiers, exact request/census/full-clock graph and fixed boundary suppliers. Node schedules remain exactly empty at every height. Thus the owner has no descendant schedule/history storage. Bootstrap spec slots contain only independent profile/config storage and an all-zero expected ID; they never enter positive admission. Earlier child slots must have already been replaced by genuine derived keys. Their fixed supplier rows cannot be replaced by a scalar claim or success flag.

Publication stores `closed-input-window-{i}.b5wm2` and `closed-input-node-{i}.b5ir5` under exclusive bounded artifact I/O. The independent original native and carrier loaders remain unchanged. No received key selects setup, no rounded/padded logical proof census is admitted, and absent/extra window or node arrays reject before parent processing. The selected setup identity versions ordered keys, exact topology, true whole-job/native/carrier pins and empty node schedule digests.

This solves the actual selected durable route for instance-pinned local closure. It does not establish reusable geometry or final self-contained block key reconstruction: rebuild still reads genuine original native/carrier proofs and previous node proofs because original verifier planning includes capture-dependent geometry. The final block goal still needs an independently reconstructible expected root key recipe without original proof files, authenticated compact public suppliers, and complete source/register/program/global compensation closure. Existing host public-policy validation costs are retained. No end-to-end speed or proof execution is claimed.

Pure fixtures cover true65-window/17-leaf/7-node census, allocation cleanup, empty node schedule/domain separation, unadmitted future slot ownership, namespace/length admission, original owner release with surviving metadata Budget, cap failures and unfinished-owner rejection. Retained production bodies include real CPU publish/reconstruct, native/carrier fresh verification, all original WM rows and new closed-node rows, key derivation, actual parent prover, final fresh root transfer, readRoot and teardown; they are never invoked by fixtures.
