Status: approved initial contract transaction; implementation in progress.

- Slice: https://github.com/teddyjfpender/stwo-zig/issues/336
- RFC: https://github.com/teddyjfpender/stwo-zig/issues/352
- Recorded decision: https://github.com/teddyjfpender/stwo-zig/issues/352#issuecomment-6749772175
- Owner: ethereum-statement (@teddyjfpender).

The first checkpoint extracts exact existing SHA256 and durable directory-file bodies
from product adapters. Sole-primitive callers bind their real private owner, leaving
product state, input admission, profiles, proof pins and public package APIs intact.
The product package, typed Owner move, consumer compatibility and strict P-3 gate
remain unfinished; this checkpoint does not claim package/workspace acceptance for
the final transaction. Additional public removals/providers require the precise
amended ledger and recorded decision in the RFC before implementation.

Pre-edit target: net code growth zero; at most +800 contained private ownership,
build/compatibility and P-3 wiring. Flags/scripts zero; no new top-level launcher.
Moves receive no removal credit. Hosted CPU and frozen Native proof-byte gates
remain the acceptance safety net; GPU validation is deferred.

The neutral Owner foundation is now implemented on the existing umbrella;
full hosted type/execution/proof acceptance is still pending. The existing
session/result aliases and canonical identities remain intact.

The canonical `secp256k1_recovery_memory_abi` is the exact existing 168-byte
fixed memory ABI, including recovery status, word order and its pinned test.
The canonical `binary_node9` is the complete fixed ETN0/ETN1 sponge/AIR,
including Row, build/evaluate, bus constraints and both original tests. Its
historical memory/program enum labels select existing domain framing in RV64;
they do not perform Ethereum guest admission. No domain parameter, second
implementation, new security claim or public provider surface is introduced.
The retained node test directly imports its existing canonical permutation
table instead of the upper infra-trace facade.

The exact two primitive module providers are approved in RFC352 decision
https://github.com/teddyjfpender/stwo-zig/issues/352#issuecomment-6750858196.
Their complete existing twenty/twenty-five-name public surfaces are pinned by
reachable signature tests, with framing/rejection invariants. This retains the
node's existing inferred delegated error behavior; it adds no catch-all or
claim of a new finite error set. The frontend major version is staged as1.0.0
for the same approved C4 transaction. Product API transfers remain unfinished.

The typed lifecycle provider and intact fixed-table ownership move are approved:
https://github.com/teddyjfpender/stwo-zig/issues/352#issuecomment-6751270792.
The existing returned session's source-visible allocator, memory/CPU/cache,
ELF metadata, trace/host/input, options, clocks/maps/counters, authority/tag,
continuation and status fields retain their exact definitions/defaults. They
remain governed by init/start/resume/run/deinit ownership and publication rules;
this adds no field, mutator, mutable accessor or alternative teardown path.
The fixed-table Descriptor/Columns remain intact above with their existing
36-word serialization and product compatibility testing path.
