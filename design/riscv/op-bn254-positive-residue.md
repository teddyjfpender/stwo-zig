# Conditional positive residue certificate source

The source proves the field relation `z*c*seed^L = ONE`, where `L = 6*x+2+p−p²+p³`, using the canonical BN254 tower `i²=−1, v³=9+i, w²=v` and coordinate order `i+2*v+6*w`. It is a conditional certificate for an independently supplied Miller value z, not a complete pairing or VM result. Curve/subgroup/infinity validity, the actual Miller z computation and authenticated external input joins remain separate gates.

The fixed exponent6*x+2 is29,793,968,203,157,093,288 (65 bits). The program uses64 general dense squares and36 multiplies for that power, then one inverse check and five tail products:42 dense multiplies total. Three source-owned Frobenius maps supply seed^p, seed^(p²), seed^(p³). A private canonical inverse of seed^(p²) must multiply it to the full12-coordinate ONE. Both that endpoint and the final residue endpoint are immutable obligations. No cyclotomic-square shortcut or native correction is assumed.

The source compiles an exact `r | L` check. It also checks that `(p⁶−1)` divides the final exponent `(p¹²−1)/r`. Thus if the certificate holds, its inverse obligation makes seed nonzero, and c lies in Fp6, raising the relation to the final exponent yields z^E=ONE. This is a field-relation argument; it does not establish the upstream pairing inputs or whole-protocol security.

Frobenius coefficients are canonical, Q/seed-independent source literals. Each pair is conjugated for powers1/3 and multiplied by the appropriate literal pair; power2 uses no conjugation. Literal factors are `xi^((p^k−1)*e/6)` for e=(0,2,4,1,3,5) in the exact flattened pair order. The generated table has27 distinct canonical scalar values, including ZERO and ONE. The optimized results match independent generic exponentiation by p, p² and p³ on the retained real four-pair certificate's nontrivial seed.

Scale c has only six free canonical hint writers. Its upper six Fq12 coordinate IDs alias the immutable literal ZERO writer in the actual source DAG. This is not a constructor-only shape convention: later z*c reads must close against that ZERO value under typed local SSA. The critical negative fixture uses a false generator pairing's nonzero z, seed=ONE, and the unrestricted full inverse c=z^-1. All field equations and both ONE endpoints then hold, but c_high is nonzero. Injecting those bytes into the multiplication leaves arithmetic valid and is rejected by source read consistency against the ZERO IDs. The physical fixture now rejects this attack even when the malicious child claims fake zero-valued high-coordinate reads and passes its standalone GKR closure: the terminal source binding evaluates the actual committed multiplication inputs.

The30 private canonical hints (seed12, c_low6, inverse2_12) use the shared `bn254_hint`95-column authority. They are free canonical writers, not trusted host values; inverse and residue products constrain their uses. The five-role physical fixture links those actual95-column hint rows to the shared BYTE table and typed SSA reads; their canonicality is enforced by the shared emitter, rather than a host-side flag.
