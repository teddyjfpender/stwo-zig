# OP R7 execution-root qualification

R7 is an explicit outer recursion protocol. It preserves the native v3 source
suite and existing OP guest/AIR ABI. The receiver chooses outer formats from
its independently admitted inventory: CPU leaves use eight-role R7, catalog
and Miller leaves use their qualified six-role R6 source factories, and every
binary parent uses R7. No incoming proof or key packet selects that policy.
R7 and R6 flags are mutually exclusive; historical defaults stay unchanged.

The shared native-source adapter runs only after fresh fragment verification.
It exposes borrowed typed views synchronously. Shape, sampled-value and local
proof buffers expire on callback return; immutable source keys and durable
outer proofs own their retained data. A take-once template token ensures errors
cannot silently transfer or double-free GKR shape advice. Pending node files
are never completion authority.

The producer's final callback runs only after native inventory, shared RAM,
KIO/Wire and terminal closure. `Receiver.prepare` independently re-establishes
source image, span/coverage/adjacency, manifest, all physical claims and the
43-byte terminal output. Its admitted leaf frames determine one canonical
ordered tree; odd final nodes carry unchanged. R7 uses its own fold domain.
Every parent key is independently compiled from known ordered child keys.
The final receiver repeats this derivation with pinned source data and bounded
shape advice, then verifies one root. It never opens the native proof bundle.

The complete actual-small gate qualifies block 120,794,432 with three leaves
and two reductions. It preserves and fresh-verifies the exact previously
qualified R7 CPU leaf, then newly proves classic Keccak/SHA leaves and both
parents. The retained CPU option is test-only. Normal CLI production proves
its CPU leaf. Neither qualification timings nor retained work are presented
as full fresh block production latency.

The source-only receiver rejects missing/duplicate/reordered coverage,
balanced service debts that preserve aggregate sums, altered terminal policy,
canonical claim corruption and a valid same-profile proof of a circuit that
merely guesses the desired root. The wrong-source R7 positive control owns an
explicit constrained empty DOT; the authority's missing-DOT refusal remains
intact. R6 uses the same test corpus through an explicit six-role adapter;
its retained root and source identities remain accepted unchanged.

See `vectors/reports/rv64-opstack-cpu-20261109/native-dot/complete-small-execution-root-v2.json`
for receipts and precise scope. The 680,116-byte final root is functionally
qualified on this actual block. A whole-protocol R7 security composition and
matched heavy-block timing remain separate work. No heavy execution/proving
rerun or order-of-magnitude improvement is claimed. Detached sponge, uniform
R7 service lowering, immutable outer setup reuse and the classic Keccak
wrapper's wide representation are subsequent optimization candidates.
